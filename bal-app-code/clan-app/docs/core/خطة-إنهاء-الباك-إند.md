# 🗺️ خطة إنهاء الباك إند — «بال» (قبل أي تعديل — بانتظار موافقتك)

> **القاعدة:** كل قسم = باك إند + قاعدة → اختبار حي → (لاحقاً) شاشة Flutter مربوطة.
> **الترتيب:** ننفذ بالترتيب ده — كل قسم يتحقق حي قبل ما نكمل اللي بعده.
> **الحالة:** خطة معروضة للاعتماد — لا تنفيذ قبل «موافق».

## القسم 2 — الصداقة والرسائل 🟡 (موجود جزئياً — يحتاج إعادة تشكيل)

**الموجود الآن:** محادثات + طلبات مراسلة (10/يوم) + حظر + بحث + متابعة اجتماعية + تقارير.
**المطلوب (من رؤيتك):** نظام «انستقرام» — الصداقة هي الأساس.

| المهمة | التفصيل |
|---|---|
| نموذج الصداقة | جدول `Friendship` (مُرسِل + مُستقبِل + حالة PENDING/ACCEPTED) |
| رسالة لغير صديق | تُنشئ **طلب صداقة** (رسالة واحدة فقط — ممنوع رسائل تانية) |
| قائمة الطلبات | واردة + قبول/رفض (عند القبول: تتحول الرسالة الأولى لمحادثة مفتوحة) |
| الكتم (Mute) | جديد — كتم إشعارات شخص (مع الحظر الموجود) |
| البروفايل العام | إنجازات + ساعات تركيز + شعبية + عدد أصدقاء + تاريخ انضمام (معلومات عامة فقط) |
| البحث | بالاسم أو الاهتمام (الاهتمام = Domain) |
| حد يومي | 10 طلبات صداقة/يوم |

**محتاج أسألك:** (في الأسئلة بالأسفل)

---

## القسم 3 — العشائر 🟡 (موجود — يحتاج تعديل حدود + تحديات)

**الموجود الآن:** عامة حسب المجال (بلا مالك) + خاصة (قائد) + كود دعوة + حظر/طرد + تحدي استيقاظ.
**المطلوب (من رؤيتك):**

| المهمة | التفصيل |
|---|---|
| **حدود جديدة** | خاصة: 15 عضو · إنشاء = 1 كحد أقصى (موجود) · انضمام = 7 كحد أقصى (جديد) · عامة = 2 كحد أقصى (موجود) |
| **تحدي تركيز جماعي** (في الخاصة) | إنشاء (صاحب العشيرة) → **إشعار** للأعضاء (قبول/تأجيل) → المقبولون → **غرفة انتظار بشات مؤقت** → صاحب الجلسة يضغط «دخول» → دورة مخصصة (مدة تركيز + راحة ≤10 + تكرار) |
| ممنوعات | الخروج من التركيز بعد الدخول · الراحة > 10 دقائق (في السيرفر) |
| الخروج من التحدي | مسموح فقط قبل بدء الجلسة |
| العضوية في العامة | بالتخصص (Domain) — موجود |

**محتاج أسألك:** جلسات العشيرة العامة إزاي؟ (في الأسئلة)

---

## القسم 4 — التركيز (فردي + جماعي) 🟡 (موجود — يحتاج الدورة المخصصة)

**الموجود الآن:** جلسات + نبض عالمي 120د + وضع صارم + كشف ساهي + شرارات.
**المطلوب (من رؤيتك):**

| المهمة | التفصيل |
|---|---|
| **الدورة المخصصة (فردي)** | مدة تركيز (يحددها) + راحة 1-10 (يحددها) + تكرار (دورات) — **آخر دورة = لوبي مش راحة** |
| **الدورة المخصصة (جماعي)** | نفس الفردي + دعوات أصدقاء → غرفة انتظار → صاحب الجلسة يبدأ |
| **راحة ≤ 10 صارمة** | تحقق في السيرفر (يرفض أي طلب راحة > 10) |
| الشرارات | نكمل بالمعدلات المعتمدة (0.45 فردي / 0.75 جماعي) |
| كشف الساهي + الوضع الصارم | موجود — نكمل بيهم (مش متناقضين مع رؤيتك)؟ **سؤال** |

---

## القسم 5 — المنبه 🔴 (موجود — يحتاج إصلاح + ربط الـ AI)

**الموجود الآن:** منبهات + مسألة HMAC + تحديات استيقاظ + **مسار wake-log ناقص**.
**المطلوب (من رؤيتك):**

| المهمة | التفصيل |
|---|---|
| إصلاح | إضافة `POST /api/alarms/wake-log` (موجود في المنطق — ناقص في الراوتر) |
| **غفوة → AI** | استدعاء الـ AI → رسالة تحفيزية ساخرة (نص — والصوت لاحقاً) |
| تكرار الغفوة | كل ضغطة غفوة → نداء AI جديد (بتصعيد) — المنبه لا يقف إلا بالاستيقاظ |
| **إثبات عشوائي** | عند «استيقظت»: السيرفر يختار عشوائياً (مشي 10 خطوات **أو** مسألة حسابية) — العميل لا يحدد |
| تسجيل الاستيقاظ | WakeLog + شرارات + سلسلة |
| **مشي 10 خطوات** | كيف نتحقق؟ **سؤال** |

---

## القسم 6 — التوثيق الأسبوعي 🟡 (موجود — يحتاج تعديل رؤيتك)

**الموجود الآن:** أهداف + أسابيع + 4 أسئلة + نافذة 5 دقائق.
**المطلوب (من رؤيتك):**

| المهمة | التفصيل |
|---|---|
| **6 أسئلة** | محتاجين نحددهم بالظبط (أقترحهم وأنا؟) |
| **زر «+»** | حقول سؤال/إجابة مخصصة (نظام بلوجات) |
| نافذة التعديل | **10 دقائق** (بدل 5) بعد الحفظ |
| القفل | ممنوع التعديل بعد النافذة — قراءة فقط |
| الأسبوع الجديد | بنفس الأسئلة — **فارغة** (كل أسبوع مستقل) |

---

## القسم 7 — المهام 🟡 (موجود — يحتاج بلوكات + AI كامل)

**الموجود الآن:** بلوكات مهام + خطوات + 6 نغمات + تنبيه 5 دقائق + نبض AI بعد المهمة.
**المطلوب (من رؤيتك):**

| المهمة | التفصيل |
|---|---|
| **البلوك الجديد** | اسم + من/إلى + **تقويم متعدد الأيام** (يوم 15 و20 → تتكرر في الاتنين) |
| **روتين** | خيار: يومي أو ليوم واحد فقط |
| **AI قبل المهمة** | Job مجدول → نداء AI → إشعار بنصيحة (قبل الموعد بـ 5 دقائق) |
| **AI وقت المهمة** | Popup «المهمة بدأت» (بدون AI) |
| **AI بعد المهمة** | سؤال: «عملت إيه؟» → تحفيز أو احتواء + حلول (موجود جزئياً — نكمل) |
| قواعد عدم اللوم | في نظام الـ AI (موجود — نتأكد من تفعيله) |
| الهدف | 10 مهام في < 5 دقائق (واجهة لاحقاً) |

## 📌 أسئلتي قبل التنفيذ (مهمة جداً — عشان ما نبنيش غلط)

1. **الاهتمامات**: المستخدم يختار **اهتمام واحد** ولا **2** (بما إنك قلت حد أقصى 2 عشائر عامة)؟ وإذا 2 — يختارهم في التسجيل؟
2. **الصداقة**: هل فيه **متابعة (Follow)** منفصلة عن الصداقة؟ ولا بس صداقة (طلب → قبول → محادثة)؟
3. **جلسات العشيرة العامة**: نظام «النبض» الحالي (كل ساعتين تلقائياً للجميع) ولا **جلسات مجدولة يدوياً** يعلنها أحدهم؟
4. **التحدي الجماعي**: للعشيرة **الخاصة فقط** ولا العامة كمان؟ وحد أقصى للمشاركين في التحدي؟
5. **مشي 10 خطوات**: السيرفر مش هيقدر يتحقق بنفسه — نقبل **إثبات من التطبيق** (عداد الخطوات Pedometer) بثقة مع سقف؟
6. **صوت الـ AI (TTS)**: نبدأ **نص فقط** (والشاشة تعرض الكلام)؟ ولا **جمل مسجلة مسبقاً**؟ ولا **TTS سحابي** (مفتاح ElevenLabs/Google — تكلفة)؟
7. **التوثيق**: الـ 6 أسئلة — **أقترحها وأنا وتوافق** (أو ابعتهم إنت)؟
8. **كتم (Mute)**: المقصود **كتم إشعارات شخص معين**؟ (مش حذف المحادثة)
9. **الأولوية للمهام**: نكمل بفئات (حرجة/نمو/سريعة) ولا كل المهام متساوية؟
10. **الإشعارات (Push)**: نكتفي **بتخزين الإشعارات في القاعدة** والفرونت يعرضها (لحد ما توصّل FCM)؟

## ✅ أمر التنفيذ المقترح (بعد موافقتك + إجاباتك)

```
1. القسم 2 (صداقة + رسائل + بروفايل + بحث + كتم)   ← يبني على الموجود
2. القسم 5 (المنبه: wake-log + غفوة AI + إثبات عشوائي)
3. القسم 7 (المهام: بلوكات + روتين + AI قبل/بعد)
4. القسم 6 (التوثيق: 6 أسئلة + + + نافذة 10د)
5. القسم 4 (التركيز: دورة مخصصة + جماعي + راحة ≤10)
6. القسم 3 (العشائر: حدود + تحديات + غرف انتظار)
```
