# 🎨 دستور التصميم المينيمالي الحديث وضوابط الواجهات (Modern Minimalist UI/UX System)

**المرجع الإلزامي والمعيار المعتمد لتطوير الواجهات وتجربة المستخدم (Senior UI/UX & Frontend Guidelines)**

تم اعتماد هذه الوثيقة كدستور ثابت ودائم يتم تطبيقه في كافة مراحل بناء وتطوير الواجهات الأمامية لمنع عيوب التصميم النمطية للذكاء الاصطناعي ولضمان واجهات احترافية، بسيطة، وسلسة بنسبة 100%.

---

## 🚫 ١. منع الإيموجيات تماماً (Zero Emojis Policy)
* **يُمنع منعاً باتاً** استخدام الإيموجيات في أزرار التحكم، القوائم، أو العناوين.
* الاعتماد الحصري على **أيقونات SVG هندسية بسيطة وواضحة** (مثل نظام Lucide Icons / Feather Icons) وعند الضرورة الوظيفية القصوى فقط.
* تجنب استخدام الرموز التعبيرية كبدائل للأيقونات أو كعناصر تزيينية في نصوص الواجهة.

---

## 🎨 ٢. تناسق الألوان المقتصد (Restricted 3-Color Palette)
* **الالتزام بـ 3 ألوان كحد أقصى:**
  1. **اللون الأساسي للعلامة (Primary Brand Color):** Champagne Gold / Accent خفيف.
  2. **اللون المحايد (Grayscale / Neutral):** خلفيات الأوبسيديان الداكنة والنصوص بدرجات الرمادي الفضي المتدرج (Slate / Mist).
  3. **لون التمييز الخفيف (Subtle Accent):** مخصص فقط لحالات الإنجاز أو الحالات النشطة.
* **تجنب التدرجات اللونية الحادة (No Heavy Gradients):** استخدام أسطح مسطحة أو شبه شفافة متناسقة.
* **منع الألوان الفسفورية أو الصارخة.**
* **منع تلوين كل زر بلون مختلف:** توحيد نمط الأزرار والعناصر لمنع الفوضى البصرية.

---

## 🔘 ٣. تصميم الأزرار والعناصر (Modern Component Architecture)
* **تجنب الأزرار البارزة بشكل قديم أو المبالغ في حجمها.**
* تصميم الأزرار ليكون ناعماً وبسيطاً بحواف متناسقة ومريحة (`rounded-md` / `rounded-lg`).
* استخدام ظلال خفيفة وناعمة جداً (`shadow-sm`) لتندمج العناصر بسلاسة تامة مع خلفية التطبيق دون حواف فاقعة أو إطارات مبالغ فيها.

---

## 🧹 ٤. إزالة الحشو والازدحام (Anti-Bloat & Whitespace First)
* **الالتزام المطلق بمبدأ "Clean & Minimalist".**
* تجنب حشو الشاشات بكروت إحصائيات وهمية، أو أقسام فرعية زائدة، أو نصوص تحفيزية طويلة لا طائل منها.
* **إعطاء الأولوية للمساحات الفارغة المريحة للعين (Whitespace):** ترك هوامش ومسافات كافية بين العناصر لمنع التكدس البصري.
* التركيز الحصري على **الوظيفة الأساسية (Core Utility)** لكل شاشة وزر.

---

## ⚠️ ٥. ضوابط تجنب أخطاء الـ UX الشائعة (AI UX Pitfalls Prevention)

### أ. تسلسل الخطوط الصارم (Strict Typography Scale)
* الالتزام بـ **3 أحجام خطوط كحد أقصى** داخل الشاشة الواحدة:
  1. **عنوان رئيسي (Heading):** خط عربي واضح ومحدد.
  2. **نص بديل/فرعي (Secondary Text):** قراءة مريحة بألوان حيادية.
  3. **نص الزر/الإجراء (Action Text):** مباشر ومقروء.
* تجنب تشتيت عين المستخدم بتعدد الأحجام والأوزان العشوائية.

### ب. نصوص الأزرار المباشرة (Direct Actionable Copy)
* استخدام كلمات مباشرة ومختصرة جداً داخل الأزرار (مثل: **"حفظ"**، **"تعديل"**، **"إلغاء"**، **"بدء"**).
* منع الجمل الطويلة أو العبارات العاطفية المفرطة داخل مساحة الزر.

### ج. حالات العناصر التفاعلية (Micro UI States)
* تصميم حالات ناعمة وبسيطة جداً عند:
  - الضغط والتفاعل (`Active / Pressed`) بفيزياء لمسية 0ms.
  - التحميل والانتظار (`Loading`).
  - التعطيل وعدم الإتاحة (`Disabled`).
* دون إضافة عناصر بصرية صارخة أو حركات فجة.

### د. التجاوب وتناسق التخطيط (Responsive Layout & Zero Overflow)
* التجاوب الكامل والمثالي مع كافة قياسات الشاشات (الهواتف، الأجهزة اللوحية، المتصفحات).
* **منع ظهور شريط التمرير الأفقي (No Accidental Horizontal Scroll)** في أي صفحة أو نافذة منبثقة.
* احتواء كافة النصوص والعناصر داخل حدود الشاشة بشكل تلقائي ومرن.
