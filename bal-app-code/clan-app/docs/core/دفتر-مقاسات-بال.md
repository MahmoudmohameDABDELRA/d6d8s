# 🧵 دفتر مقاسات «بال» — جلسة أسئلة الأقسام
> زي الخياط قبل ما يقص: ناخد كل قياساتك على كل قسم في التطبيق قبل ما نبني حرف واحد.
> **طريقة الاستخدام:** كل قسم فيه أسئلة بخيارات (أ/ب/ج) + سطر حر. جاوب براحتك — ولو حابب تختصر، اختار الحروف بس.

## ✂️ القسم 0 — الهوية العامة (المقاس الأساسي)

**س 0.1 — إحساس التطبيق الأول؟**
- أ) فخامة ملكية راقية
- ب) هدوء وسكينة (زي جلسة تأمل)
- ج) طاقة شبابية حماسية (زي لعبة)
- د) جدية احترافية (زي أداة عمل)
- هـ) مزيج: ______________

**س 0.2 — الخلفية العامة؟**
- أ) داكنة فاحمة (أسود/كحلي عميق)
- ب) فاتحة ناعمة (كريمي/ساج فاتح)
- ج) متدرجة (داكنة مع توهج خفيف في الأعلى)
- د) شيء تاني: ______________

**س 0.3 — اللون الرئيسي (اللي يلفت النظر)؟**
- أ) ذهبي شامباني
- ب) أخضر غابي/ساج
- ج) أزرق كهربائي
- د) نحاسي/برتقالي دافئ
- هـ) أبيض/أسود صرف (مونوكروم)
- و) لون تاني: ______________

**س 0.4 — اللون الثانوي (للمساحات والبطاقات)؟**
- أ) نفس درجة اللون الرئيسي لكن أفتح
- ب) رمادي محايد
- ج) أبيض شفاف (زجاجي)
- د) متدرج غامق
- هـ) تاني: ______________

**س 0.5 — شكل الأزرار والكروت؟**
- أ) زجاجية شفافة بحواف ناعمة (Glassmorphism) ← اللي اخترته
- ب) مسطحة نظيفة بحدود رفيعة
- ج) غامقة بظلال خفيفة
- د) مزيج: ______________

**س 0.6 — حرفية اللوجو؟**
- أ) حرف "ب" منقوش
- ب) أيقونة (درع / جبل / عين / شعلة / يدين)
- ج) اسم "بال" كامل بخط جميل
- د) مزيج أيقونة + اسم
- هـ) فكرة تانية: ______________

**س 0.7 — اللغات؟**
- أ) عربي فقط (RTL)
- ب) عربي + إنجليزي (تبديل)
- ج) عربي أساسي + إنجليزي كخيار لاحق
