# 🏛️ دليل الرؤية الشاملة والمعمارية والمخطط العام لمشروع Clan App
**Clan App — The Living Ecosystem & Group Focus Productivity Platform**

---

## 🌟 ١. رؤية المشروع والقيمة الجوهرية (Project Vision & Core Value)
**Clan App** ليس مجرد أداة إنتاجية أو قائمة مهام جافة؛ بل هو **منظومة حية ورفيق فكري واجتماعي (Living Ecosystem)** يجمع بين:
1. **التركيز التكتيكي الجماعي (Group Focus & Squad Lobby)**: ردهة استعداد تشبه ألعاب النخبة، حماية كاملة من المقاطعة (Sacred DND)، وكشف الساهي المباغت.
2. **منبه المعركة الصارم (Offline Battle Alarm)**: منبه ذكي عتادي متدرج الصوت مع سكتش تفاعلي للـ AI، وإلزام بحل مسألة حسابية أو المشي ١٠ خطوات أو التصوير في الضوء لإيقاف الرنين.
3. **المرافق الذكي الاستباقي (Gemini AI Co-Pilot)**: صاحب جدع يفهم سياق المستخدم كاملاً، يذكره بالمهام قبل موعدها بـ ٥ دقائق بنصيحة تكتيكية، ويسأله بعد إنجاز المهمة بـ ١٠ أسئلة متناوبة حتمية، ويدعمه عاطفياً في الفوز والخسارة والتعب دون أي جلد ذات.
4. **قسم المسودات الحرة والإملاء الصوتي الحي (Drafts Hub & Voice Dictation)**: تفريغ الأفكار بالصوت العربي المباشر عبر Web Speech API وفلاتر، وحفظها محلياً وسحابياً في PostgreSQL، ورفعها بنقرة واحدة لتحليلها وتفكيكها عبر الذكاء الاصطناعي.
5. **التوثيق الأسبوعي (Weekly Goal Journal & Time Capsule)**: توثيق مسار الهدف أسبوعاً بأسبوع في كبسولات مقفولة نهائياً بعد ٥ دقائق، مع رسائل تصل للمستقبل بعد ٣٠ يوماً.
6. **مجتمع العشائر وهيبة الانتماء (Clans & Prestige Vault)**: عشيرة المسار العامة مع حماية Slow Mode، كتائب النخبة الخاصة بأكواد سرية، إطارات الأفاتار الملكية، ترددات الدماغ (بيتا وألفا وثيتا)، وهدايا الشعبية الحية.

## 📜 ٣. القواعد والدساتير الصارمة المحفوظة في المنظومة

1. **Rule 1: الاستئذان والتفويض المسبق** (*"لا تعمل شيء إلا بإذني"*).
2. **Rule 2: المرجعية الموحدة للوثيقة النهائية** (تطابق 100% بدون Placeholders).
3. **Rule 3: التجميع الكامل والترابط الحي** (ربط كامل للـ End-to-End Cycle عبر الـ UI وقاعدة البيانات والباك إند والـ AI).
4. **Rule 4: عدم قاطع للـ Mock/Fake Data** (بيانات حقيقية عبر الـ Global State و PostgreSQL).
5. **Rule 5: التصميم المينيمالي الحديث** (منع الإيموجيات 100%، باليت ثلاثي مقتصد 60-30-10، أزرار ناعمة `shadow-sm` و `rounded-md`، وتجاوب كامل بدون تمرير أفقي).
