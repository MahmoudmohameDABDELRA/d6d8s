# ⚡ تحديث حاسم — AlarmKit (iOS 26)

> **ما ورد أدناه عن قيود iOS صار قديماً جزئياً.**
> Apple أطلقت `AlarmKit` في WWDC 2025 مع iOS 26 — وهو يمنح تطبيقات
> الطرف الثالث **نفس صلاحيات تطبيق الساعة**.

## ما تغيّر

| القيد القديم | مع AlarmKit |
|---|---|
| صوت 30 ثانية فقط | ♾️ مستمر كمنبه النظام |
| لا يخترق الصامت | ✅ يخترقه |
| لا يخترق Focus/DND | ✅ يخترقه |
| لا شاشة كاملة | ✅ شاشة كاملة + Dynamic Island |
| يموت بعد Restart | ✅ ينجو (مخزّن في النظام) |
| **يحتاج Critical Alerts** | ❌ **لم يعد مطلوباً** |
| حد على عدد المنبهات | ♾️ بلا حد |

## المطلوب فقط

```xml
<!-- Info.plist -->
<key>NSAlarmKitUsageDescription</key>
<string>لجدولة منبهات الاستيقاظ ومؤقتات التركيز</string>
```

```swift
import AlarmKit
let status = try await AlarmManager.shared.requestAuthorization()
```

**لا طلب خاص من Apple. لا انتظار أسابيع.**

## ⚠️ الشرط الوحيد: iOS 26+

مستخدمو iOS 17–25 يحتاجون المسار القديم (UserNotifications).
الاستراتيجية الصحيحة:

```swift
if #available(iOS 26.0, *) {
    // AlarmKit — تجربة كاملة
} else {
    // UserNotifications + إشعارات متتالية (المشروح أدناه)
}
```

## 📊 الكفاءة بعد التحديث

```
أندرويد:      95%
iOS 26+:      95%  ← كان 70%
iOS 17–25:    70%  (المسار القديم)
```

# ⚠️ تصحيح مهم أولاً

## لا يمكن الكتابة في منبه النظام

**لا أندرويد ولا iOS يسمحان** لأي تطبيق بإضافة منبه في تطبيق الساعة الرسمي.
هذه حماية أساسية — لولاها لأضاف كل تطبيق منبهات في هاتفك.

**الاستثناء الوحيد (أندرويد):**
```java
Intent(AlarmClock.ACTION_SET_ALARM)
```
يفتح تطبيق الساعة **بشاشة إضافة منبه مملوءة**، والمستخدم يضغط «حفظ» بنفسه.
لا مقابل له في iOS إطلاقاً.

## البديل الذي يحقق نفس النتيجة

التطبيق يجدول المنبه في **نظام التشغيل نفسه** (لا في تطبيق الساعة).
هذا يعمل في كل الحالات التي تهمّك:

| الحالة | يعمل؟ |
|---|---|
| التطبيق مقفول تماماً (swiped away) | ✅ |
| **إعادة تشغيل الهاتف** | ✅ *بشرط* |
| بلا إنترنت | ✅ |
| التطبيق ليس في الخلفية | ✅ |
| الوضع الصامت | ✅ (بإعداد صحيح) |

**الشرط:** كود يسمع حدث الإقلاع ويعيد الجدولة — مشروح أدناه.

# 1️⃣ التخزين المحلي — أساس كل شيء

المنبهات تُحفظ على الجهاز، والخادم للمزامنة فقط.

```js
// storage/alarms.js
import AsyncStorage from '@react-native-async-storage/async-storage';

const KEY = '@alarms';

export const saveAlarms = async (alarms) =>
  AsyncStorage.setItem(KEY, JSON.stringify(alarms));

export const loadAlarms = async () => {
  const raw = await AsyncStorage.getItem(KEY);
  return raw ? JSON.parse(raw) : [];
};
```

> **القاعدة:** الجهاز هو مصدر الحقيقة للجدولة. الخادم مصدر الحقيقة للسجل.
> بلا إنترنت يعمل المنبه كاملاً، والسجل يُرفع لاحقاً.

# 2️⃣ الجدولة

```js
// services/alarmScheduler.js
import notifee, {
  AndroidImportance,
  AndroidCategory,
  TriggerType,
  RepeatFrequency,
} from '@notifee/react-native';

import { loadAlarms } from '../storage/alarms';

const CHANNEL_ID = 'battle-alarm';

/** قناة الإشعارات — تُنشأ مرة واحدة */
export const setupChannel = async () => {
  await notifee.createChannel({
    id: CHANNEL_ID,
    name: 'منبه المعركة',
    importance: AndroidImportance.HIGH,
    sound: 'alarm',          // ملف في android/app/src/main/res/raw/
    vibration: true,
    vibrationPattern: [300, 500, 300, 500],
    bypassDnd: true,         // يتجاوز «عدم الإزعاج»
  });
};

/** أقرب موعد قادم لهذا اليوم من الأسبوع */
const nextOccurrence = (time, weekday) => {
  const [h, m] = time.split(':').map(Number);
  const now = new Date();
  const date = new Date();

  date.setHours(h, m, 0, 0);

  let delta = (weekday - date.getDay() + 7) % 7;
  if (delta === 0 && date <= now) delta = 7;  // فات اليوم ⇒ الأسبوع القادم

  date.setDate(date.getDate() + delta);
  return date;
};

/**
 * جدولة منبه واحد.
 * ⚠️ إشعار منفصل لكل يوم — Notifee لا يدعم «أيام محددة» في تكرار واحد.
 */
export const scheduleAlarm = async (alarm) => {
  if (!alarm.isActive) return;

  for (const weekday of alarm.days) {
    const fireDate = nextOccurrence(alarm.time, weekday);

    await notifee.createTriggerNotification(
      {
        id: `alarm-${alarm.id}-${weekday}`,
        title: '⏰ منبه المعركة',
        body: `حان وقت ${alarm.time} — قم وحلّ المسألة`,
        data: { alarmId: alarm.id, scheduledTime: alarm.time },
        android: {
          channelId: CHANNEL_ID,
          category: AndroidCategory.ALARM,
          importance: AndroidImportance.HIGH,
          // يفتح شاشة كاملة حتى والجهاز مقفول — كالمكالمة الواردة
          fullScreenAction: { id: 'wake-screen', launchActivity: 'default' },
          pressAction: { id: 'default', launchActivity: 'default' },
          ongoing: true,        // لا يُمسح بالسحب
          autoCancel: false,
          loopSound: true,
        },
        ios: {
          sound: 'alarm.wav',
          critical: true,       // يتجاوز الوضع الصامت
          criticalVolume: 1.0,
          interruptionLevel: 'critical',
        },
      },
      {
        type: TriggerType.TIMESTAMP,
        timestamp: fireDate.getTime(),
        repeatFrequency: RepeatFrequency.WEEKLY,
        alarmManager: {
          allowWhileIdle: true,   // ← يتجاوز Doze في أندرويد
        },
      },
    );
  }
};

/** إعادة جدولة كل شيء من الصفر — تُستدعى بعد الإقلاع أو أي تعديل */
export const rescheduleAll = async () => {
  await notifee.cancelAllNotifications();
  await setupChannel();

  const alarms = await loadAlarms();
  for (const alarm of alarms) await scheduleAlarm(alarm);

  return alarms.length;
};

export const cancelAlarm = async (alarmId, days) => {
  for (const d of days) {
    await notifee.cancelNotification(`alarm-${alarmId}-${d}`);
  }
};
```

# 3️⃣ 🔴 إعادة التشغيل — النقطة الحرجة

**بعد إعادة تشغيل الهاتف، أندرويد يمسح كل المنبهات المجدولة.**
بلا هذه الخطوة، منبهك لن يرنّ بعد أول إعادة تشغيل.

## أندرويد — الإذن والمستقبِل

`android/app/src/main/AndroidManifest.xml`:

```xml
<manifest>
  <!-- منبهات دقيقة (أندرويد 12+) -->
  <uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM" />
  <uses-permission android:name="android.permission.USE_EXACT_ALARM" />

  <!-- ⚠️ الأهم: السماع لحدث الإقلاع -->
  <uses-permission android:name="android.permission.RECEIVE_BOOT_COMPLETED" />

  <uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
  <uses-permission android:name="android.permission.VIBRATE" />
  <uses-permission android:name="android.permission.WAKE_LOCK" />

  <application>
    <!-- Notifee يعيد الجدولة تلقائياً بعد الإقلاع -->
    <receiver
      android:name="app.notifee.core.ReceiverService"
      android:exported="false">
      <intent-filter>
        <action android:name="android.intent.action.BOOT_COMPLETED" />
        <action android:name="android.intent.action.QUICKBOOT_POWERON" />
      </intent-filter>
    </receiver>
  </application>
</manifest>
```

## طلب إذن المنبهات الدقيقة (أندرويد 12+)

```js
import notifee, { AndroidNotificationSetting } from '@notifee/react-native';
import { Alert, Linking } from 'react-native';

export const ensureExactAlarmPermission = async () => {
  const settings = await notifee.getNotificationSettings();

  if (settings.android.alarm !== AndroidNotificationSetting.ENABLED) {
    Alert.alert(
      'إذن المنبهات الدقيقة',
      'التطبيق يحتاج إذناً ليرنّ المنبه في وقته بالضبط',
      [
        { text: 'لاحقاً', style: 'cancel' },
        { text: 'فتح الإعدادات', onPress: () => notifee.openAlarmPermissionSettings() },
      ],
    );
    return false;
  }

  return true;
};
```

## شبكة أمان عند فتح التطبيق

حتى مع المستقبِل، أعد الجدولة عند كل فتح — يضمن التعافي من أي فشل:

```js
// App.js
import { useEffect } from 'react';
import { AppState } from 'react-native';

import { rescheduleAll } from './services/alarmScheduler';

export default function App() {
  useEffect(() => {
    rescheduleAll();   // عند كل فتح

    const sub = AppState.addEventListener('change', (state) => {
      if (state === 'active') rescheduleAll();
    });

    return () => sub.remove();
  }, []);

  // ...
}
```

## iOS

لا يحتاج مستقبِل إقلاع — النظام يحفظ الإشعارات المجدولة عبر إعادة التشغيل تلقائياً.

**لكن:** `critical: true` يحتاج **موافقة خاصة من Apple**:
👉 https://developer.apple.com/contact/request/notifications-critical-alerts-entitlement

بلا هذه الموافقة، المنبه لن يتجاوز الوضع الصامت.
**خطة بديلة:** `interruptionLevel: 'timeSensitive'` — يتجاوز «عدم الإزعاج» بلا موافقة خاصة.

# 4️⃣ شاشة الاستيقاظ

```js
import notifee, { EventType } from '@notifee/react-native';

// التطبيق مغلق تماماً — يعمل في الخلفية
notifee.onBackgroundEvent(async ({ type, detail }) => {
  if (type === EventType.PRESS && detail.notification?.data?.alarmId) {
    // التنقل يحدث عند فتح التطبيق
  }
});

// التطبيق مفتوح
notifee.onForegroundEvent(({ type, detail }) => {
  if (type === EventType.PRESS) {
    navigation.navigate('WakeScreen', {
      alarmId: detail.notification.data.alarmId,
      scheduledTime: detail.notification.data.scheduledTime,
    });
  }
});
```

**في شاشة الاستيقاظ:**

```js
// 1. اطلب المسألة من الخادم
const { task } = await api.get('/api/alarms/wake-task');
// { question: "39 − 15 = ؟", token: "eyJ...abc" }

// 2. المستخدم يجيب
const res = await api.post('/api/alarms/wake-task/solve', {
  token: task.token,
  answer: userAnswer,
  alarmId,
  scheduledTime,
  responseSec: elapsed,
});

// 3. أوقف الصوت وأغلق الإشعار
await notifee.stopForegroundService();
await notifee.cancelDisplayedNotification(notificationId);
```

> **لماذا المسألة من الخادم؟** لو وُلّدت محلياً لأمكن قراءة الإجابة من الكود.
> التوقيع HMAC يمنع التزوير أيضاً.

# 5️⃣ المزامنة مع الخادم

```js
export const syncAlarms = async () => {
  try {
    const { alarms } = await api.get('/api/alarms');   // مصدر الحقيقة
    await saveAlarms(alarms);
    await rescheduleAll();
    return true;
  } catch {
    // بلا إنترنت — المنبهات المحلية تكفي
    await rescheduleAll();
    return false;
  }
};
```

**متى تُستدعى:** عند فتح التطبيق · بعد أي تعديل · عند عودة الاتصال.

# ✅ قائمة التحقق

| # | البند | لماذا |
|---|---|---|
| 1 | `RECEIVE_BOOT_COMPLETED` | **بدونه المنبه يموت بعد إعادة التشغيل** |
| 2 | `SCHEDULE_EXACT_ALARM` | بدونه يتأخر دقائق (أندرويد 12+) |
| 3 | `allowWhileIdle: true` | يتجاوز Doze |
| 4 | `AndroidCategory.ALARM` | يعامله النظام كمنبه لا إشعار |
| 5 | `fullScreenAction` | شاشة كاملة والجهاز مقفول |
| 6 | `bypassDnd: true` | يتجاوز «عدم الإزعاج» |
| 7 | `rescheduleAll()` عند الفتح | شبكة أمان |
| 8 | التخزين المحلي | يعمل بلا إنترنت |
| 9 | موافقة Critical Alerts (iOS) | لتجاوز الصامت |

# 🧪 كيف تختبر فعلياً

```
1. اضبط منبهاً بعد 3 دقائق
2. اقفل التطبيق تماماً (اسحبه من قائمة التطبيقات)
   → يجب أن يرنّ ✅

3. اضبط منبهاً بعد 5 دقائق
4. أعد تشغيل الهاتف
5. لا تفتح التطبيق إطلاقاً
   → يجب أن يرنّ ✅   ← هذا الاختبار الحاسم

6. فعّل وضع الطيران
   → يجب أن يرنّ ✅

7. فعّل «عدم الإزعاج»
   → يجب أن يرنّ ✅ (يحتاج bypassDnd و critical)
```

**الاختبار رقم 5 هو الأهم.** لو فشل، راجع `RECEIVE_BOOT_COMPLETED`.

# ⚠️ مصنّعون يحتاجون خطوة إضافية

Xiaomi · Huawei · Oppo · Vivo · Samsung — لديهم مدير بطارية عدواني يقتل
المنبهات المجدولة.

```js
import { Alert, Linking, Platform } from 'react-native';

const AGGRESSIVE = ['xiaomi', 'huawei', 'oppo', 'vivo', 'samsung', 'oneplus'];

export const checkBatteryOptimization = async () => {
  if (Platform.OS !== 'android') return;

  const brand = (await DeviceInfo.getBrand()).toLowerCase();
  if (!AGGRESSIVE.includes(brand)) return;

  const isOptimized = await notifee.isBatteryOptimizationEnabled();

  if (isOptimized) {
    Alert.alert(
      'مهم لعمل المنبه',
      'هاتفك قد يوقف المنبه لتوفير البطارية.\nافتح الإعدادات واستثنِ التطبيق.',
      [
        { text: 'لاحقاً', style: 'cancel' },
        { text: 'فتح', onPress: () => notifee.openBatteryOptimizationSettings() },
      ],
    );
  }
};
```

استدعِها **مرة واحدة** بعد إنشاء أول منبه — لا في كل فتح.

# الخلاصة

**لا يمكن** الكتابة في تطبيق الساعة — لا أندرويد ولا iOS.

**لكن** الجدولة في نظام التشغيل تعطي النتيجة نفسها: يرنّ والتطبيق مقفول،
وبعد إعادة التشغيل، وبلا إنترنت.

**الشرط الوحيد:** `RECEIVE_BOOT_COMPLETED` + مستقبِل Notifee.
بدونه يموت المنبه بعد أول إعادة تشغيل.
