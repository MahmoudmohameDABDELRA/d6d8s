**مشروع**: Clan App Backend (`clan-app-backend`)  
**المسارات**: `/api/tasks/batch-blocks` و `/api/tasks/timeline-schedule` و `/api/tasks/sound-themes`  
**التاريخ**: 9 أغسطس 2026  
**الحالة**: مبني ومختبر حياً ومدمج 100%

## ١. النظرة المعمارية الشاملة

تم تصميم هذا المحرك للقضاء تماماً على "فخ التنظيم المفرط وإرهاق التخطيط (Planning Fatigue)"؛ بحيث يستطيع المستخدم فتح التطبيق والضغط على زر `(+)` واحد، وتحديد اسم المهمة واختيار عدة أيام من التقويم بنقرات سريعة وتحديد نطاقها الزمني، مع إدراج نغمات تنبيه هادئة وتفعيل تنبيه مسبق تلقائي قبل موعد المهمة بـ ٥ دقائق.

```
[ العميل يفتح زر (+) ويملأ البلوكات ]
                   │
                   ▼
     POST /api/tasks/batch-blocks
                   │
 ┌─────────────────┴─────────────────┐
 ▼                                   ▼
١. تعيين نغمة مجهزة                  ٢. تفعيل تنبيه مسبق بـ 5 دقائق
   (ZEN_BELL / WARRIOR_CHIME)           (Pre-Task Reminder Alarm)
 │                                   │
 └─────────────────┬─────────────────┘
                   ▼
 ٣. توليد وتوزيع المهام على التقويم والجدول اليومي المرتب (Timeline View)
```

---

## ٢. النغمات الجاهزة المسبقة (Built-in Sound Themes)

يحتوي النظام على **٦ نغمات مدمجة وثابتة** في الباك إند:
1. 🔔 **جرس زن هادئ (`ZEN_BELL`)** *(الافتراضي)*: رنين تأملي هادئ يساعد على التهيؤ الذهني للتركيز.
2. ⚔️ **رنين المحارب (`WARRIOR_CHIME`)**: نغمة تحفيزية ملحمية للمهام الحرجة والكبرى.
3. 🎵 **قيثارة ناعمة (`GENTLE_HARP`)**: أوتار استرخاء لطيفة ومريحة.
4. ⚡ **موجة النبض (`PULSE_WAVE`)**: نبضات إلكترونية حديثة وسريعة.
5. 🌅 **عصافير الصباح (`MORNING_BIRDS`)**: تغريد طبيعي لبدايات الصباح الباكر.
6. 🧘 **صنج عميق (`DEEP_GONG`)**: صوت عميق لقطع التشتت والبدء الفوري.

* **تنبيه الـ ٥ دقائق الافتراضي (`reminderMinutesBefore: 5`)**: إعداد ثابت ومجهز تلقائياً يقوم بتنبيه المستخدم قبل بدء وقت المهمة بـ ٥ دقائق لتهيئة نفسه والانطلاق.

* **الوظيفة**: إنشاء مهام متعددة عبر أيام متباينة وبأوقات مخصصة ونغمات محددة داخل معاملة ذرية واحدة (`prisma.$transaction`).

### ٣. المشاوير السريعة العابرة — `POST /api/tasks/quick-errand`
* **الوظيفة**: إنشاء مشوار سريع بنقرة واحدة بدون حقول معقدة (مثل: *"مشوار لعم محمد أجيب الأغراض"*).
* **جسم الطلب (JSON)**:
```json
{
  "title": "مشوار لعم محمد أجيب الأغراض 🛍️",
  "date": "2026-08-10",
  "startTime": "15:30"
}
```

### ٤. استعراض النغمات المتاحة — `GET /api/tasks/sound-themes`
* يرجع مصفوفة النغمات الـ ٦ مع الإيموجي والوصف وإعداد التنبيه المسبق الافتراضي (5 دقائق).

## ٤. نتائج الفحص الحي والاختبارات (100% Pass Rate)

1. تم اختبار المنظومة عبر `npm run test:blocks` وحققت نسبة نجاح **4 من أصل 4 اختبارات بنسبة 100%**.
2. تم تشغيل واختبار المسارات حياً على السيرفر الفعلي:
   * تم استدعاء `sound-themes` $\rightarrow$ ردت بالنغمات الـ 6 والتنبيه الـ 5 دقائق.
   * تم إنشاء بلوكين لـ 5 مهام عبر 3 أيام متباينة $\rightarrow$ تم إنشاؤها بنجاح في معاملة واحدة (`201 Created`).
   * تم طلب `timeline-schedule` $\rightarrow$ تم إرجاع المهام مرتبة زمنياً من الصباح (06:00) إلى المساء (18:00).
   * تم إنشاء مشوار سريع $\rightarrow$ تم حفظه برتبة `QUICK` و `isQuickErrand = true`.
