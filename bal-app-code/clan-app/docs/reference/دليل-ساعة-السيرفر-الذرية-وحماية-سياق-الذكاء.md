## ١. المشكلة والدافع الهندسي (The Temporal Hallucination Problem)

عند التحدث مع نماذج الذكاء الاصطناعي (مثل Google Gemini)، لا تمتلك النماذج ساعة داخلية متصلة بالزمن الحقيقي؛ فإذا سأل العميل: *"الساعة كام دلوقتي؟"* أو *"هو النهاردة إيه؟"* أو *"اضبط لي منبه كمان ساعتين"*:
* **المشكلة الكارثية**: يقوم النموذج بتخمين واختراع توقيت عشوائي أو افتراض توقيت خوادم أمريكا (UTC/PST)، مما يؤدي لجدولة منبهات في أوقات خاطئة أو إعطاء نصائح ليلية في الصباح الباكر!

## ٢. الحل الهندسي المنفّذ: ساعة السيرفر الذرية الصارمة (The Server-Authoritative Clock)

تم بناء محرك توقيت ذري في `src/services/aiContext.service.js` يقوم تلقائياً بقراءة المنطقة الزمنية للمستخدم (`user.timezone` مثل `Africa/Cairo` أو `Asia/Riyadh`)، وحساب الوقت اللحظي الدقيق بالساعة والدقيقة واليوم في الأسبوع وفترة اليوم (صباح، ظهيرة، مساء، ليل)، وحقنها **في أول سطر من سياق المحادثة** قبل إرسال أي حرف للنموذج:

```
[ العميل يرسل رسالة للـ AI ]
              │
              ▼
[ السيرفر يقرأ توقيت العميل: Africa/Cairo ]
              │
              ▼
[ توليد ساعة السيرفر الذرية وحقنها في السطر الأول ]
" [ساعة السيرفر الذرية الحقيقية]: الأحد ٩ أغسطس ٢٠٢٦ | الساعة الآن: ٦:٠٢ ص (الصباح 🌅) | بتوقيت: Africa/Cairo "
              │
              ▼
[ إرسال السياق لـ Gemini 2.5 / 3.0 Flash ]
              │
              ▼
 الـ AI يرد بدقة مطلقة دون أي كذب أو هلوسة في التوقيت والمنبهات
```

## ٣. بنية كائن التوقيت في كود السيرفر (`aiContext.service.js`)

```javascript
const tz = user.timezone || 'Africa/Cairo';
const now = new Date();

const dateFormatted = new Intl.DateTimeFormat('ar-EG', {
  timeZone: tz,
  weekday: 'long',
  year: 'numeric',
  month: 'long',
  day: 'numeric',
}).format(now);

const timeFormatted = new Intl.DateTimeFormat('ar-EG', {
  timeZone: tz,
  hour: 'numeric',
  minute: '2-digit',
  hour12: true,
}).format(now);

const hour24 = parseInt(
  new Intl.DateTimeFormat('en-US', {
    timeZone: tz,
    hour: 'numeric',
    hour12: false,
  }).format(now),
  10,
);

let periodOfDay = 'الصباح 🌅';
if (hour24 >= 12 && hour24 < 17) periodOfDay = 'الظهيرة ☀️';
else if (hour24 >= 17 && hour24 < 22) periodOfDay = 'المساء 🌙';
else if (hour24 >= 22 || hour24 < 5) periodOfDay = 'الليل 🌌';

const clock = {
  timezone: tz,
  date: dateFormatted,
  time: timeFormatted,
  hour24,
  periodOfDay,
  isoTimestamp: now.toISOString(),
};
```
