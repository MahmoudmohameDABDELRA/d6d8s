## ٢. مسارات الـ REST API والمواصفات الفنية

جميع المسارات محمية بالمصادقة `Authorization: Bearer <TOKEN>` وتتطلب اكتمال إعداد الحساب (`requireOnboarded`).

---

### ١. التحكم في الخصوصية والحساب الخاص — `PATCH /api/social/privacy`
* **الوظيفة**: تفعيل/تعطيل الحساب الخاص والتحكم في إخفاء أو إظهار الستريك وساعات التركيز وآخر ظهور ونطاق استقبال الرسائل المباشرة.
* **جسم الطلب (JSON)**:
```json
{
  "isPrivateAccount": true,
  "showLastSeen": false,
  "showStreak": false,
  "showFocusHours": true,
  "dmPrivacy": "FOLLOWERS_ONLY",
  "privacyLevel": "REQUESTS_ONLY"
}
```
* **الرد (200 OK)**:
```json
{
  "success": true,
  "message": "تم تحديث إعدادات الخصوصية بنجاح 🔒",
  "privacy": {
    "id": "0a354648-...",
    "username": "yasmin_biz",
    "isPrivateAccount": true,
    "showLastSeen": false,
    "showStreak": false,
    "showFocusHours": true,
    "dmPrivacy": "FOLLOWERS_ONLY",
    "privacyLevel": "REQUESTS_ONLY"
  }
}
```

---

### ٢. تحديث الحالة اللحظية والروابط المهنية — `PATCH /api/social/status`
* **الوظيفة**: تخصيص بايو الحساب، الإيموجي المعبر، والحالة التعبيرية اللحظية (مثل "أذاكر لامتحان الفاينل 🚀")، وروابط التواصل (GitHub, LinkedIn, Twitter/X, Portfolio).
* **جسم الطلب (JSON)**:
```json
{
  "customStatus": "أبني النسخة الأسطورية من التطبيق 🚀",
  "statusEmoji": "🚀",
  "bio": "مهندس برمجيات ومحب للتركيز العميق في المشاريع الكبرى",
  "socialLinks": {
    "github": "https://github.com/tariq",
    "linkedin": "https://linkedin.com/in/tariq",
    "twitter": "https://x.com/tariq_dev"
  }
}
```

---

### ٣. متابعة مستخدم أو إرسال طلب متابعة — `POST /api/social/follow/:targetUserId`
* **المنطق السيرفري الصارم**:
  * **إذا كان الحساب عاماً (`isPrivateAccount: false`)**: تتم المتابعة فوراً برمز `ACCEPTED` وتزيد عدادات المتابعين والمتابَعين ذرياً في نفس المعاملة، ويصل للطرف الآخر إشعار متابعة.
  * **إذا كان الحساب خاصاً (`isPrivateAccount: true`)**: يُنشأ طلب متابعة معلق برمز `PENDING`، ولا تزيد العدادات ولا تنكشف البيانات إلا بعد موافقة صاحب الحساب.
* **نموذج الاستجابة للحساب الخاص (200 OK)**:
```json
{
  "success": true,
  "status": "PENDING",
  "message": "حساب خاص 🔒 تم إرسال طلب المتابعة بنجاح بانتظار موافقة صاحب الحساب"
}
```

---

### ٤. قبول أو رفض طلبات المتابعة — `POST /api/social/requests/:requestId/respond`
* **جسم الطلب**: `{"action": "ACCEPT"}` أو `{"action": "REJECT"}`.
* **المنطق**: عند القبول تتحول العلاقة إلى `ACCEPTED` وتزيد العدادات ويصل إشعار تأكيد للطرف الآخر؛ وعند الرفض يُحذف الطلب نهائياً.

---

### ٥. استعراض الملف الشخصي المخصص مع حجب البيانات — `GET /api/social/profile/:userId`
* **كشف العلاقات التلقائي (Relationship Detection)**:
  * `IS_ME`: ملفي الشخصي.
  * `FOLLOWING`: متابع ومقبول.
  * `REQUESTED`: أرسلت طلباً معلقاً.
  * `NOT_FOLLOWING`: لست متابعاً.
* **حجب البيانات للحسابات الخاصة (Dynamic Redaction)**:
  * إذا كان الحساب خاصاً وغير متابع، يرجع السيرفر `isRestricted: true` ويحجب: ساعات التركيز، سلسلة الستريك، رصيد الشرارات، وآخر ظهور، مع إرجاع البيانات العامة فقط (الاسم، البايو، الأفاتار، اللقب المجهز، والعدادات).
* **نموذج استجابة الحساب المقيد (200 OK)**:
```json
{
  "success": true,
  "isRestricted": true,
  "message": "هذا الحساب خاص 🔒 تابع الحساب لرؤية إحصائياته الكاملة ونشاطه",
  "profile": {
    "id": "1d20f9da-...",
    "username": "yasmin_biz",
    "profileImage": null,
    "bio": "ريادة أعمال ومشاريع ناشئة",
    "domain": "BUSINESS",
    "specialty": "ENTREPRENEUR",
    "isPrivateAccount": true,
    "customStatus": "جلسة عصف ذهني 💡",
    "statusEmoji": "💡",
    "followersCount": 45,
    "followingCount": 30,
    "equippedTitle": null,
    "relationship": "NOT_FOLLOWING",
    "totalFocusHours": null,
    "currentStreak": null,
    "longestStreak": null,
    "lastSeen": null
  }
}
```

---

### ٦. البلاغات الرقابية والمراجعة الإدارية — `POST /api/social/report`
* **الأسباب المدعومة**: `SPAM` (إزعاج)، `HARASSMENT` (مضايقة)، `INAPPROPRIATE` (محتوى غير لائق)، `CHEATING` (تلاعب)، `OTHER`.
* **لوحة الإدارة (`/api/social/admin/reports`)**:
  * `GET /api/social/admin/reports`: استعراض البلاغات المعلقة مع تفاصيل المبلغ والمبلغ عنه.
  * `PATCH /api/social/admin/reports/:reportId/resolve`: البت في البلاغ (`RESOLVED` أو `DISMISSED`) مع إمكانية حظر الحساب فورياً (`banUser: true`).
