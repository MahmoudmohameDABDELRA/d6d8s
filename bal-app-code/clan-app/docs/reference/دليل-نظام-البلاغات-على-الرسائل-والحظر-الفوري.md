**المسارات**: `/api/chat/messages/:messageId/report*` و `/api/admin/reports/*`  
**التاريخ**: 9 أغسطس 2026  
**الحالة**: مبني ومختبر حياً ومدمج 100%

---

## ١. النظرة المعمارية الشاملة

تم تصميم هذا النظام لحماية المستخدمين من أي مضايقات أو شتائم داخل المحادثات الفردية وعشائر المنصة، مع تطبيق قاعدة **"توثيق الأدلة الفوري (Content Snapshot Preservation)"** التي تمنع الجاني من التملص بحذف الرسالة، مع تمكين الضحية من **الإبلاغ والحظر التلقائي بنقرة واحدة (One-Click Report & Block)**.

```
[ الجاني يرسل شتائم في الشات ]
              │
              ▼
[ الضحية يضغط: إبلاغ وحظر فوري 🚨 ]
              │
 POST /api/chat/messages/:messageId/report-and-block
              │
 ┌────────────┴────────────┐
 ▼                         ▼
١. أخذ لقطة فورية للنص     ٢. إنشاء قيد حظر فوري (BlockedUser)
   (Content Snapshot)         يمنع الجاني من المراسلة فورياً برمز 403
 │                         │
 └────────────┬────────────┘
              ▼
 ٣. وصول البلاغ بكامل أدلته إلى لوحة تحكم الإدارة
    (حتى لو حذف الجاني الرسالة، يظل النص موثقاً أمام المشرف)
              │
              ▼
 ٤. المشرف يبت في البلاغ ويحظر حساب الجاني نهائياً بنقرة واحدة
```

## ٢. مسارات الـ API والمواصفات الفنية

جميع المسارات محمية بالمصادقة `Authorization: Bearer <TOKEN>`.

---

### ١. الإبلاغ على الرسالة المحددة فقط — `POST /api/chat/messages/:messageId/report`
* **الوظيفة**: التقاط لقطة فورية من نص الرسالة وتوثيقها كبلاغ رسمي للمشرفين دون حظر الطرف الآخر.
* **جسم الطلب (JSON)**:
```json
{
  "reason": "HARASSMENT",
  "details": "توجيه شتائم وإساءة صريحة في المحادثة"
}
```
* **الرد (201 Created)**:
```json
{
  "success": true,
  "message": "تم توثيق لقطة الرسالة كدليل قاطع وإرسال البلاغ للإدارة بنجاح 🛡️",
  "reportId": "8cc45a87-...",
  "isBlocked": false,
  "contentSnapshot": "[المرسل: Omar] رسالة شتم وإهانة صريحة ومباشرة!"
}
```

---

### ٢. الإبلاغ على الرسالة + الحظر الفوري التلقائي — `POST /api/chat/messages/:messageId/report-and-block`
* **الوظيفة**: تنفيذ عملية ذرية مزدوجة داخل `prisma.$transaction`:
  1. توثيق وحفظ لقطة الإدانة من نص الرسالة المحددة (`contentSnapshot`).
  2. إنشاء قيد حظر تلقائي في جدول `BlockedUser` يمنع المعتدي فوراً من إرسال أي رسائل جديدة.
* **الرد (201 Created)**:
```json
{
  "success": true,
  "message": "تم توثيق الدليل وإرسال البلاغ للإدارة وحظر المستخدم فورياً 🛡️",
  "reportId": "9fa812c3-...",
  "isBlocked": true,
  "contentSnapshot": "[المرسل: Omar] رسالة شتم وإهانة صريحة ومباشرة!"
}
```

---

### ٣. التحقق الصارم في خادم الشات لمنع المحظورين من الإرسال
* تم تعزيز دالة `assertAccess` في `src/services/chat.service.js` بحيث تتحقق تلقائياً في أي محادثة ثنائية (`conv.type === 'DIRECT'`) من عدم وجود حظر متبادل بين الطرفين:
```javascript
if (conv.type === 'DIRECT') {
  const other = await prisma.conversationParticipant.findFirst({
    where: { conversationId, userId: { not: userId } },
  });

  if (other && (await isBlocked(userId, other.userId))) {
    throw forbidden('لا يمكن إرسال أو قراءة رسائل في هذه المحادثة (حساب محظور)', 'BLOCKED');
  }
}
```

---

### ٤. لوحة الإدارة ومراجعة الأدلة المحفوظة — `GET /api/admin/reports`
* يستعرض المشرف البلاغات مع ظهور الحقول التوثيقية:
  * `targetType`: نوع البلاغ (`CHAT_MESSAGE`, `CLAN_MESSAGE`, `USER_PROFILE`, `COMMENT`).
  * `messageId`: معرّف الرسالة.
  * `contentSnapshot`: **لقطة نص الإساءة كما كُتبت في الأصل** ومحفوظة حتى لو حذف المعتدي الرسالة لاحقاً من الشات.
* **البت والحظر الإداري بنقرة واحدة (`PATCH /api/admin/reports/:reportId/resolve`)**:
  * جسم الطلب: `{"action": "RESOLVED", "actionNote": "ثبوت الإساءة", "banUser": true}`.
  * يقوم بحظر حساب المعتدي وتصفير توكنات دخوله فورياً.

## ٣. نتائج الفحص الحي والتحقق الأمني (100% Pass Rate)

تم تنفيذ سيناريو هجوم حقيقي على السيرفر الشغال على المنفذ `3000`:
1. قام الجاني `omar_abuser` بإرسال رسالة شتم لسارة.
2. قامت سارة بالضغط على `report-and-block`.
3. حاول الجاني إرسال رسالة ثانية $\rightarrow$ تم صده برمز **`403 Forbidden (BLOCKED)`**.
4. قام الجاني بحذف رسالته من قاعدة البيانات للهروب من العقوبة $\rightarrow$ أصبحت `isDeleted = true`.
5. فتح المشرف لوحة الإدارة `GET /api/admin/reports` $\rightarrow$ وجد لقطة نص الشتيمة موثقة بالكامل في `contentSnapshot`.
6. اتخذ المشرف قرار الحظر $\rightarrow$ تم حظر حساب الجاني نهائياً `isBanned = true`.
