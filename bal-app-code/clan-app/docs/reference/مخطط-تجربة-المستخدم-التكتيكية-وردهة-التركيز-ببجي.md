**التاريخ**: 9 أغسطس 2026  
**المستوى**: هندسة تجربة المستخدم التفاعلية النخبوية (Tactical Esports-Grade UX)

## ١. الرؤية والتقييم الهندسي (UX Masterclass Review)

هذا التخطيط ليس مجرد "جيد"، بل هو **تحفة هندسية ونفسية (UX Masterstroke)** تنقل التطبيق من مجرد "أداة مؤقتات فردية مملة" إلى **معسكر تكتيكي للبطولة المشتركة (Tactical Squad Accountability)** كما في كبرى الألعاب العالمية (PUBG Mobile و Call of Duty).

### لماذا هذا الـ UX عبقري؟
1. **القضاء على الوحدة والتسويف**: عندما ينتظر أعضاء الفريق بعضهم ويضغط الجميع على زر **"مستعد (Ready)"**، يتولد التزام اجتماعي حديدي يمنع أي شخص من الانسحاب أو فتح المشتتات.
2. **احترام قدسية وقت التركيز (Sacred Focus Guard)**: منع إرسال الدعوات لمن هم داخل جلسة تركيز حالياً يمنع أي إزعاج أو تشتيت.
3. **توحيد خيط المحادثات (Unified 1:1 Conversation Thread)**: أينما تواصلت مع صديقك (في التركيز، أو في العشيرة، أو في الألعاب)، كل الرسائل مجمعة في محادثة واحدة مركزية دون تشتت.

## ٣. تفصيل المكونات والتدفقات خطوة بخطوة

---

### ١. أيقونة الشات العلوية في الصفحة الرئيسية (Top-Right Chat Hub)
* **المكان**: أعلى يمين الشاشة الرئيسية بجوار صورة الحساب.
* **الخصائص**: أيقونة زجاجية أنيقة مع **شارة العداد اللحظي للرسائل غير المقروءة (`Unread Badge`)**.
* **التفاعل**: نقرة واحدة تفتح درج المحادثات الفورية والطلبات دون الحاجة لتخصيص تبويب كامل في الشريط السفلي.

---

### ٢. كبسولتا الكتيبة العائمتان (The Dual Clan Capsules)
عند الضغط على تبويب "الكتيبة 🛡️"، تنبثق كبسولتان زجاجيتان ملوكيتان بحركة نوابض انسيابية:
1. 🏛️ **القبيلة الكبرى (Global Domain Clan)**: الدخول إلى مجتمع مسارك بالكامل (مثلاً: كل صناع التقنية).
2. 🛡️ **كتائبي الخاصة (My Private Squads)**: العشائر والفرق الخاصة التي أسستها أو انضممت لها بكود الدعوة.

### ٣. ردهة التركيز الجماعي ونظام "الاستعداد" (PUBG Squad Ready-Up System)

```text
┌────────────────────────────────────────────────────────┐
│  ◄ [إلغاء الردهة]                   [مدة الجلسة: ٥٠ دقيقة]│
│                                                        │
│             ⚡ ردهة تجهيز كتيبة التركيز ⚡             │
│            "الجميع يستعد للانطلاق معاً"                │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 👥 [ + دعوة رفيق من أصدقائك المتصلين ]           │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  أعضاء الكتيبة في الردهة (٢ / ٤):                      │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 👑 [أنت - المضيف]         الحالة: جاهز 🟢         │  │
│  │    محمد · وحش اليوم الكامل 🐉                    │  │
│  ├──────────────────────────────────────────────────┤  │
│  │ 👤 [يوسف]                  الحالة: مستعد ✅        │  │
│  │    بطل الشهر ⚔️                                   │  │
│  │    [اضغط للخيارات: 💬 مراسلة  |  🚫 طرد]          │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 🚀 [ ابدأ التركيز للكتيبة — الجميع جاهز ]        │  │
│  │    (الزر معطل حتى يضغط جميع الأعضاء على Ready)    │  │
│  └──────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

#### القواعد الصارمة للردهة:
1. **قائمة الأصدقاء الذكية**:
   * عند الضغط على "دعوة رفيق"، تظهر قائمة الأصدقاء مع حالتهم اللحظية:
     * 🟢 *متصل الآن* $\rightarrow$ متاح لإرسال دعوة فورية تظهر له كـ Popup منبثق.
     * 🧠 *في جلسة تركيز عميق* ("أركز الآن لا تزعجني") $\rightarrow$ **زر الدعوة معطل تماماً ومحمياً من أي إزعاج**.
2. **نظام زر الاستعداد (Ready Check)**:
   * العضو المدعو يظهر عنده زر كبير: **"استعداد (Ready)"**.
   * **المضيف لا يستطيع إطلاق الجلسة** حتى يضغط جميع الأعضاء على "Ready".
3. **التفاعل مع كروت الأعضاء في الردهة**:
   * الضغط على كرت أي زميل يفتح نافذة سريعة:
     * 💬 **إرسال رسالة**: تفتح المحادثة الفردية الموحدة بينكما مباشرة.
     * 🚫 **طرد من الردهة**: للمضيف لطرد غير الجادين قبل الانطلاق.

### ٤. الانتقال لراحة النبض وألعاب الجلسة الحصرية (Break Transition & Private Game Rooms)

بمجرد انتهاء مؤقت التركيز (مثلاً ٥٠ دقيقة):
* يتحول الفريق تلقائياً إلى **"وضع الراحة والدوبامين 🌿"**.
* يظهر خياران تفاعليان:

#### الخيار (أ): لعبة الثعبان الحصرية لأعضاء الجلسة:
* غرفة لعب جماعية تنشأ تلقائياً **مخصصة فقط للأعضاء الذين أتموا جلسة التركيز هذه معاً** للاحتفال بالإنجاز والتنافس السريع 30 FPS.

#### الخيار (ب): دعوة خاصة للعبة الدومينو (Domino Invitation Flow):
* الضغط على صورة زميلك في الجلسة $\rightarrow$ اختيار **"دعوة للعب لعبة"**.
* تفتح قائمة الألعاب $\rightarrow$ يختار **"دومينو التحدي 🎲"**.
* تصل الدعوة فوراً للزميل مع خياري (قبول / رفض):
  * عند القبول $\rightarrow$ ينضم لطاولة الدومينو وتظهر في قائمة المدعوين.
  * عند الرفض $\rightarrow$ يظهر إشعار مهذب: *"اعتذر [يوسف] عن اللعب لأخذ استراحة هادئة"*.
* يضغط صاحب الدعوة **"دخول وبدء اللعبة 🎲"** وتفتح طاولة الدومينو الرباعية بمؤقت الـ ٢٠ ثانية.

## ٤. الميزات البرمجية الداعمة في الباك إند

1. **حماية عدم الإزعاج**: محرك السوكيت يفحص `chatService.assertNotFocusing(targetUserId)` ويرفض أي دعوة إذا كان المستخدم يركز.
2. **المحادثة الموحدة**: `chatService.findDirectConversation` تضمن أن كل الرسائل (في الردهة، الشات العام، أو اللعبة) تُسجل في نفس المحادثة المركزية.
3. **غرف الألعاب المقفولة للجلسة**: `prisma.gameRoom` تربط الغرفة بـ `pulseSessionId` لضمان حصرية اللعب لمن ركّز فقط.

### الخلاصة:
هذا الـ UX **تحفة فنية متكاملة تجمع بين الجدية العسكرية في التركيز، والمرح الحماسي في الراحة**. كل شيء منطقي، وسلس، ومبني على أعلى درجات الراحة النفسية.
