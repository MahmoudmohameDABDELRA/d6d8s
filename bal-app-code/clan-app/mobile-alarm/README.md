# Clan Alarm

منبه أندرويد و iOS بيخترق الصامت ووضع عدم الإزعاج.

---

## المشكلة اللي حصلت قبل كده

الملفات كانت بأسماء عربية، و**PowerShell 5.1 مش بيقرا UTF-8** — فالنص العربي اتحوّل لرموز مكسورة وكسر السكربت.

**الحل:** كل حاجة إنجليزي دلوقتي. السكربت `install.ps1` ASCII خالص.

---

## الملفات

| الملف / الفولدر | إيه ده |
|---|---|
| **`install.ps1`** | ← **ده اللي تشغّله** |
| `android/` | ٨ ملفات Kotlin |
| `ios/` | ملفات Swift |
| `js/` | ٤ ملفات JavaScript |

باقي الملفات متلمسهاش — السكربت بينقلها.

## الخطوات

### 1) المكتبة الوحيدة

```powershell
cd C:\bbbb\ClanApp
npm install @react-native-async-storage/async-storage
```

### 2) شغّل السكربت

```powershell
cd C:\bbbb\clan-app-backend\mobile-alarm
Set-ExecutionPolicy Bypass -Scope Process
.\install.ps1 -ProjectPath "C:\bbbb\ClanApp"
```

عايز تشوف الأول من غير تعديل؟ زوّد `-DryRun` في الآخر.

### 3) شاشة الاختبار

افتح `C:\bbbb\ClanApp\App.tsx` وامسح كل اللي فيه وحط ده:

```jsx
import React from 'react';
import TestScreen from './src/alarm/TestScreen';

export default function App() {
  return <TestScreen />;
}
```

### 4) ابنِ

وصّل موبايلك وفعّل **USB Debugging**، وبعدين:

```powershell
cd C:\bbbb\ClanApp
npx react-native run-android
```

أول بناء ٥–١٠ دقايق.

## لما التطبيق يفتح

شاشة سودا فيها ٤ أزرار. اضغطهم بالترتيب:

**١ · اطلب الأذونات** — هيطلع سؤال، اضغط اسمح

**٢ · أعد الفحص** — هتظهر المشاكل. كل مشكلة ليها زرار بياخدك للإعدادات الصح.

أهم اتنين:
- تحسين البطارية → **بدون قيود**
- التشغيل التلقائي (شاومي/أوبو/هواوي) → **فعّله**

كرر لحد ما تشوف **✓ المنبه مضمون**.

**٣ · جرّب (١٥ ثانية)** — اضغط، وبعدها **اقفل الشاشة فوراً**.

المفروض: الشاشة تنوّر لوحدها، صوت يبدأ خفيف ويعلى، ومسألة حساب.

**٤ · الاختبار الحاسم (دقيقتين)** — اضغط، **اسحب التطبيق من قائمة المهام**، اقفل الشاشة، استنى.

لو رن وهو مقفول خالص — خلاص، المنبه شغال.

## لو حاجة وقعت

| الرسالة | الحل |
|---|---|
| `is not recognized` | إنت مش في الفولدر الصح، أو `install.ps1` مش موجود |
| `cannot be loaded` | شغّل `Set-ExecutionPolicy Bypass -Scope Process` الأول |
| `SDK location not found` | افتح Android Studio مرة واحدة |
| `Unresolved reference: localbroadcastmanager` | افتح `android\app\build.gradle` وحط في `dependencies`:<br>`implementation "androidx.localbroadcastmanager:localbroadcastmanager:1.1.0"` |
| شاشة بيضا وقت الرنين | اسم المكوّن مش مطابق — لازم `ClanAlarmScreen` |
| المنبه مبيرنش | شوف تحت ⬇ |

### تشخيص: المنبه مبيرنش

التليفون موصّل، شغّل:

```powershell
adb logcat -s ClanAlarmScheduler:* ClanAlarmReceiver:* ClanAlarmRingService:*
```

| اللي يظهر | معناه |
|---|---|
| `setAlarmClock ... @ ...` | اتجدول صح، المشكلة في التسليم |
| `fallback inexact` | الأذونات ناقصة — ارجع للزرار ٢ |
| مفيش أي سطر | الوحدة مش متسجلة |
| `received: ACTION_FIRE` وبعدين سكوت | الخدمة فشلت |

## بق مهم

لو اسم حزمتك مش `com.clanapp`، الـ Manifest بيستنى إشارة باسم قديم والكود بيبعت باسم جديد.

**النتيجة:** المنبه ميرنش خالص، من غير أي رسالة خطأ.

السكربت بيصلحها تلقائياً، والخطوة ١٠ بتتأكد. لو ركّبت يدوي انتبه لتلات الأسطر في الـ receiver.

## المستوى التقني

**أندرويد:** `setAlarmClock()` مش `setExactAndAllowWhileIdle()`.

| | setExact… | setAlarmClock |
|---|---|---|
| يخترق Doze | كل ٩ دقايق | **دايماً** |
| يخترق Battery Saver | ❌ | **✅** |
| أيقونة ⏰ | ❌ | **✅** |
| شاومي تقتله | غالباً | نادراً |

نفس اللي بيستخدمه تطبيق الساعة المدمج.

الصوت بيخرج في الصامت لأن `USAGE_ALARM` قناة منفصلة — الصامت بيكتم الرنين مش المنبه.

**iOS:** AlarmKit على iOS 26+، و UserNotifications على الأقدم. صفر مكتبات خارجية.

## اللي اتختبر

**بالتشغيل الفعلي:**
- ٧٨ اختبار منطق — كلها نجحت
- ٩ مناطق زمنية × ٤٣ اختبار = ٣٨٧ نجاح
- التوقيت الصيفي: ٢٨٬٢٢٤ حالة × ٧ مناطق
- ٤٠٠ رنّة = ٤٠٠ يوم فريد، صفر تكرار
- منطق التركيب على ٣ مشاريع وهمية

**مااتختبرش:**
- البناء نفسه (مفيش Gradle هنا)
- الرنين على جهاز حقيقي
- السكربت على PowerShell حقيقي — ASCII خالص ومتوازن، بس متجربش
