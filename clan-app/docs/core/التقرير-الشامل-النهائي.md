## 4️⃣ نظام الجبل 🏔️ (الجزء اللي بنيته — بالكامل)

### التدفق الحي (مثبت باختبار `mountain-lifecycle` 29/29):
```
المستخدم: "عاوز أتعلم Flutter"
  → POST /goals/dream         → Gemini يطرح 4 أسئلة كويز
  → POST /dream/:id/answers   → Gemini يبني خطة (5-7 أهداف) JSON
  → POST /dream/:id/approve   → Goal نشط + GoalWeek (أسبوع 1)
  → POST /steps/:stepId/journey       → Gemini يبني رحلة (أيام) JSON
  → POST /steps/:stepId/journey/approve → Journey ACTIVE + تواريخ بالأيام المحلية
  → الجوب كل 15 دقيقة (أو فتح التطبيق) → يولد مهمة اليوم في قسم المهام
  → PATCH /tasks/:id/complete → Task ✅ → JourneyDay ✅ → (كل الأيام) → GoalStep ✅ → (الكل) → القمة 🏁
```

### ⏰ مزامنة منتصف الليل المحلي (طلبتها — منفذة ومختبرة):
- `journeyScheduler.service.js`: بوابة `scheduledDate <= اليوم المحلي` (عبر `User.timezone` + `Intl`)
- الجوب `journey-daily` كل 15 دقيقة + lazy عند فتح التطبيق
- الاختبار: مستخدم UTC+14 وUTC-11 → كل واحد مهمة "نهارده" بتوقيته + يوم بكرة deferred ✅

### 📅 الجداول:
```
Goal (الحلم/الجبل) ← GoalStep (الأهداف) ← Journey (الرحلة) ← JourneyDay (الأيام)
Task: + source (MANUAL/JOURNEY) + journeyDayId (unique) + goalStepId
```
