## 5) الأزرار (Button System)

### 5.1 Pill Button (أساسي) 🟢
```
الشكل: كبسولة (زوايا 999) · ارتفاع 52px · حشوة أفقية 24px
الألوان: خلفية Primary · نص On-Primary
الظل: ناعم (blur 12px، alpha 25%)
الأنميشن: scale 0.97 عند الضغط + عودة مرنة (spring 300ms)
حالات: Default · Pressed · Disabled (40% شفافية) · Loading (Spinner)
النص: قصير (1-3 كلمات) — "ابدأ" · "أنشئ" · "تابع" · "أكمل"
الأيقونة: اختيارية قبل النص
```

### 5.2 Outline Pill (ثانوي)
```
الشكل: كبسولة · حدود 1.5px من الـ Secondary
الخلفية: شفافة · النص بلون Secondary
الأنميشن: تعبئة خفيفة (10% Primary) عند الضغط
الاستخدام: "عرض التفاصيل" · "إعادة المحاولة" · "مشاركة"
```

### 5.3 Icon Circle Button (أداة) ⭕
```
الشكل: دائرة 44px · خلفية Surface/Ghost
الأيقونة: Outline (Rounded) 22px
الأنميشن: rotate 90° عند الضغط + scale 0.9
الاستخدام: مشاركة · إغلاق · إعدادات · AI · المزيد
```

### 5.4 Hero FAB (إنشاء) ➕
```
الشكل: دائرة 60px (أكبر من الباقي) — في منتصف الناف بار
الألوان: خلفية Accent (ذهبي) في الليلي · Primary (تركواز) في النهاري
الظل: توهج ملون (glow) حول الزر
الأنميشن: عند الضغط → ينبسط لقائمة دائرية (4 خيارات) بترتيب متتابع
الخيارات: هدف جديد · مهمة · بدء تركيز · منبه
```

### 5.5 Morphing FAB (متغير الشكل)
```
دائرة 56px في الهدوء → كبسولة (أيقونة + نص) عند الحاجة (تمرير/شاشة فارغة)
التحول: 300ms spring · الأيقونة تتغير بسلاسة
الاستخدام: "إضافة مهمة" في قائمة فارغة · "إنشاء رحلة" في جبل فارغ
```

## 6) البطاقات (Card System)

### 6.1 GlassCard (الأساسية) 🪟
```
الخلفية: Glass (blur 20px + شفافية 72% ليلي / 65% نهاري)
الزوايا: Radius-XL (24) · الحدود: 1px Border خفيف
الظل: ناعم (offset 0,8 · blur 24 · alpha 15%)
الحشوة: LG (16)
الأنميشن: تدخل fade + translateY 12px → 0 (250ms easeOut)
الاستخدام: الهدف الحالي · المرحلة الحالية · رأي AI · ملخص الجلسة
```

### 6.2 CompactInfoCard (مصغرة)
```
الشكل: زوايا MD (16) · حشوة SM (12)
المحتوى: أيقونة 18px + Label (12px) + Value (16px Bold) في صف
الألوان: أيقونة Primary · Value من Text
الاستخدام: Streak · XP · ساعات التركيز · المرحلة · المهمة الجاية
```

### 6.3 MetricCard (Hero) 📊
```
الشكل: زوايا XL (24) · الخلفية Surface أو Glass
المحتوى: القيمة هي البطل — كبيرة (28-34 Bold) + Label صغير فوقها
الاستخدام: التقدم 42% · 4/10 مرحلة · 30:00 مؤقت
الأنميشن: الرقم بيتعد (TweenAnimationBuilder 800ms) عند التغيير
```

### 6.4 ActionCard (قابلة للضغط) 👆
```
الشكل: زوايا LG (20) · الخلفية Surface
المحتوى: أيقونة 20px + عنوان (16 SemiBold) + سطر (13) + Chevron ←
الأنميشن: عند الضغط → ارتفاع خفيف (translateY -2) + ظل أكبر
الاستخدام: خطة الهدف · الإنجازات · الإحصائيات · اقتراحات AI
```

### 6.5 Stage Node (عقدة المرحلة) ⛰️
```
مكتمل: دائرة 20px · أخضر (Primary) · بداخلها ✓ أبيض · Label خفيف
الحالي: دائرة 26px (أكبر) · ذهبي (Accent) · توهج نابض (Pulse 2s) · Label بارز
مقفول: دائرة 16px · رمادي (Disabled) · بداخلها قفل · Label مكتوم
الأنميشن: الانتقال بين الحالات → spring 400ms + انفجار جزيئات عند الإكمال
```

## 7) الأنميشن (Motion System)

| النوع | المدة | المنحنى | الاستخدام |
|---|---|---|---|
| Micro | 150ms | easeOut | الضغط، hover |
| Standard | 250ms | easeOutCubic | دخول البطاقات، الأزرار |
| Transition | 350ms | easeInOutCubic | تغيير الشاشات |
| Hero | 500ms | easeOutCubic | دخول العنصر البطل |
| Celebration | 800ms | spring (0.8, 1.2) | النجاح، القمة، المكافأة |
| Pulse | 2s loop | easeInOut | العقدة الحالية، الـ AI orb |
| Reduce Motion | — | احترام `disableAnimations` | إيقاف كل الحركات |

### 7.1 دخول الشاشة (Staggered Entrance)
```
1. الخلفية/السماء fade (300ms)
2. الجبل يظهر fade+scale (500ms)
3. المسار يُرسم من أسفل لفوق (1400ms)
4. العقد تظهر تباعًا (كل 100ms)
5. العقدة الحالية تتوهج (بعد الرسم)
6. البطاقات تنزلق (كل 80ms متتابعة)
7. الناف بار يطفو من تحت (400ms)
8. الـ AI orb ينبض (2s loop)
```

### 7.2 احتفال (CelebrationOverlay) 🎉
```
الاستخدام: إتمام مرحلة · إنجاز مهمة · وصول القمة
الحركة: نبضة العنصر + انفجار جزيئات (10-20) + رقم Sparks يتعد (800ms)
الألوان: ذهبي (Accent) + أخضر (Primary) + أبيض
الظهور: fade في 200ms · الاختفاء: fade 300ms بعد 1.5s
```

### 7.3 توهج العقدة الحالية ✨
```
Pulse: scale 1 → 1.15 → 1 (2s loop) + توهج خلفي (glow radius يتنفس)
اللون: ذهبي (Accent) في الليلي · تركواز (Primary) في النهاري
```

## 14) قواعد ذهبية (لا تُكسر)

1. **الشاشة مشهد بطبقات** — مش Cards مكدسة (Spatial)
2. **كل شيء طافي** — ممنوع ملزوق على الحافة (Floating)
3. **عنصر بطل واحد + إجراء أساسي واحد** لكل شاشة (Hierarchy)
4. **مساحات واسعة** — ممنوع Dense UI
5. **5% ذهبي للمكافآت فقط** — لا تستخدم الذهبي في كل مكان
6. **الأنميشن له معنى** — للدخول/الاحتفال/التأكيد، مش للزينة
7. **Reduce Motion** — احترام إعدادات الجهاز
8. **RTL عربي** — كل شيء معكوس للعربية (النص من اليمين)
9. **الخط موحّد** — IBM Plex Sans Arabic في كل مكان
10. **كل عنصر قابل للضغط واضح** — الظل/الارتفاع عند الضغط
