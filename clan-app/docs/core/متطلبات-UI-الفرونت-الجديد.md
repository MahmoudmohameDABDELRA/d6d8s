## بعد ما تيجي الباكدج — ترتيب البناء (متفق عليه)

1. **UX-1**: التعارف + التسمية + الجبل 🏔️ (مع إعداد الخطة وكويز AI والموافقة)
2. **UX-2**: دورة المهام الكاملة (بلوجات/روتين/تقويم/نكشة/Popup/سؤال بعدها) + دورة التركيز (فردي/جماعي/راحة)
3. **UX-3**: الرسائل (انستقرام) + العشائر + التحدي الجماعي (غرفة الانتظار)
4. **UX-4**: التوثيق الأسبوعي (6 أسئلة + القفل)
5. المنبه + الألعاب + اللمسات الأخيرة

كل مرحلة: شاشات حقيقية مربوطة بالباكدج الحي ومختبرة، مفيش شاشة شكلية.
