## 3. الخطوط (Typography)

- **IBM Plex Sans Arabic** — أوزان 400 / 500 / 600 / 700 (OFL مجاني، يُحزم داخل المشروع)
- **IBM Plex Sans** — مرافق للإنجليزية وكل اللغات اللاتينية (نفس العائلة = انسجام بصري تلقائي)
- Fallback: خط النظام.
- مقاس أساسي 16px · عناوين: 20 / 24 / 32 · أرقام المؤقت بخط أحادي القياس (tabular) لمنع الاهتزاز.

## 4. الحركة (Motion) — ناعم هادئ

| العنصر | المواصفات |
|--------|-----------|
| زمن قياسي | 200ms · انتقالات شاشة 250ms · تحولات كبيرة 350ms |
| المنحنيات | `easeOutCubic` للدخول · `easeInOutCubic` للانتقالات · المرونة (spring) بثبات منخفض للاحتفالات فقط (وصول القمة، إنجاز مهمة) |
| دخول البوب أب | fade + scale (0.96→1) + خلفية backdrop blur تظهر بتدريج |
| خروج البوب أب | fade + scale خفيف نحو الأسفل |
| FAB morphing | 300ms بين الدائرة والكبسولة، مع تغيير ناعم للأيقونة |
| شريط التقدم (الجبل) | حركة مستمرة بطيئة بلا اهتزاز، مع نبضة لطيفة عند اجتياز محطة |
| Reduce motion | احترام `MediaQuery.disableAnimations` → إيقاف كل الحركات |

## 5. الأزرار العائمة (FAB) — متغيرة الشكل Morphing

- **دائرة** 56px في الوضع الهادئ → **كبسولة ممتدة** (أيقونة + نص) عند الحاجة للسياق (تمرير/شاشة فارغة/إجراء أساسي).
- سطح زجاجي (glass) مع حدود خفيفة + توهج ناعم حول عنصر العمل الأساسي فقط.
- لون الأساسي: `primary` · لون التحذير/الحذف: `danger`.
- موضعها: أسفل يمين RTL (يسار بصرياً) — مسافة آمنة 16px من الحواف، بلا تداخل مع شريط التنقل.

---

## 6. البوب أبات (Modals) — زجاجي

- كارت زجاجي في المنتصف: خلفية `glass` + blur 20px + حدود شفافة خفيفة + زوايا 28px.
- الخلفية المحيطة: تعتيم + blur خفيف (2–4px) — المحتوى تحتها يبان ضبابي وهادئ.
- الدخول: fade + scale · الخروج: عكسه · إغلاق: ضغطة خارج الكارت أو زر X.
- أنواعه: تأكيدات (أيقونة + نص + زراين)، إدخال (حقول + زر رئيسي)، قوائم (Bottom Sheet زجاجي من تحت للمسارات الطويلة).

## 9. قواعد البناء الرسمية — Design Grammar (معتمدة من مرجع المالك 2026-08-13)

> المصدر: مرجع "Mountain Journey UI" (صورة + شرح UI Kit) — اللغة البصرية الاسمها:
> **Cinematic Floating Soft-Depth UI** — الشاشة مشهد واحد متعدد الطبقات، مش مجموعة Cards.

### 9.1 فلسفة الشاشة (7 طبقات بالترتيب)
```text
1. Background / Environment   (السماء والجبل)
2. Ambient Layer              (ضباب/نجوم/توهج خلفي)
3. Main Content Plane         (المحتوى الأساسي)
4. Hero Element               (الجبل = البطل البصري)
5. Floating Cards             (كروت طافية بظل ناعم)
6. Floating Actions           (أزرار طافية)
7. Floating Bottom Navigation (جزيرة طافية)
```
ممنوع النمط القديم: Header + Card + Card + Card + Button.

### 9.2 أنواع الكروت (4 أنواع فقط)
| الكارت | الاستخدام | الشكل |
|--------|-----------|-------|
| `GlassCard` | الهدف الحالي/المرحلة الحالية/رأي AI/ملخص الجلسة | زجاجي، زوايا كبيرة، ظل ناعم، حدود رفيعة |
| `CompactInfoCard` | Streak/XP/ساعات التركيز/المرحلة/المهمة الجاية | أيقونة + Label + قيمة |
| `MetricCard` (HeroMetric) | التقدم 42% / المرحلة 4/10 | القيمة هي البطل بصرياً |
| `ActionCard` | خطة الهدف/الإنجازات/الإحصائيات | أيقونة + عنوان + سطر + Chevron — كامل قابل للضغط |

### 9.3 أنواع الأزرار (3 أنواع)
1. **Primary = Floating Pill Button** (ابدأ/أنشئ/تابع/ابدأ التركيز) — بارز بصرياً
2. **Secondary = Outline Capsule Button** (التفاصيل/إعادة المحاولة/مشاركة)
3. **Utility = Circular Icon Button** (مشاركة/إغلاق/AI/إعدادات)

### 9.4 مكونات المراحل (Stage Nodes) — 3 حالات
- **Completed**: دائرة + صح ✓ + Label خفيف
- **Current**: أكبر + توهج Glow + Label ملاصق
- **Locked**: خافت + قفل + Label مكتوم
- الاسم يطلع **Pill ملاصق للـ Node** وليس داخل كارت كبير.

### 9.5 التقدم (3 أنواع)
- `ProgressRing` دائري للتقدم الإجمالي · `ProgressBar` خطي داخل الكروت · **`JourneyPath` = المسار المنحني نفسه هو التقدم** (CustomPaint/SVG — مش خط مستقيم، مش صورة ثابتة).

### 9.6 الحركة — تتابع منظم (Staggered Entrance)
```text
الجبل يظهر (fade/scale) ← الطريق يُرسم ← المرحلة الحالية تتوهج ← الكروت تنزلق
```
- Spring ناعم: اختيار العقدة/الكروت/الأزرار/الـ Nav/الـ AI orb
- EaseOut: دخول الصفحة/التقدم/رسم المسار
- **Pulse: للعنصر المهم فقط** (المرحلة الحالية + الـ AI) — مش لكل حاجة

### 9.7 التنقل — Floating Island Navigation
- جزيرة طافية دائرية الزوايا، منفصلة عن حافة الشاشة، داخلها تباعد، والنشط متظلل
- **`+` في المنتصف = Hero FAB** (أكبر من الباقي) → يفتح Create (مهمة/تركيز/هدف/منبه)
- `FloatingActionStack` (أزرار جانبية: خطة/هدف/إنجازات/إحصائيات) — **للشاشة الرئيسية فقط** مش كل شاشة

### 9.8 البوب أبات (تحسين على قرارنا الزجاجي)
- **المعلومات والإجراءات = Bottom Sheet زجاجي** (زوايا علوية كبيرة + Drag handle + CTA رئيسي + سطح منفصل)
- **التحذير الخطير = Compact Dialog زجاجي صغير** (تأكيد حذف/خروج)
- مش Dialog تقليدي لكل حاجة.

### 9.9 التغذية الراجعة
- النجاح = **Micro-Celebration**: نبضة Node + XP + انفجار جزيئات صغيرة (مش Toast)
- الخطأ = داخل العنصر نفسه (مش Snackbar لكل خطأ)

### 9.10 حالات الشاشة
- Empty State = **مصور/مكاني**: "الجبل مستني أول خطوة" + زر "ابدأ بناء خطتك" (مش No Data)
- Loading = **Skeleton + حركة مكانية**: الجبل أولاً ← الطريق ← العقد ← التقدم ← الكروت · وللـ AI: **AI Thinking Orb**
- `AICompanionOrb` طافي دائم → AI Quick Actions (اسألني/خطط لي/راجع يومي/ساعدني في الخطوة) — الـ AI حاضر بدون ما يسرق الشاشة

### 9.11 الـ Iconography
- **Rounded Outline** للنقل والإجراءات · **Filled** للحالات · معبرة للإنجازات — مفيش Heavy/Cartoon 3D

### 9.13 تحليل مرجع الصورة (فهم برمجي بالبيكسلات — 2026-08-13)
- شاشة موبايل 853×1844 · **داكن ليلي** · ألوان: كحلي ليلي `#13152C` + بنفسجي `#4C3789` + لافندر `#9D6FB1`
- أسطع نقطة أعلى الشاشة (القمة/القمر) · المسار: **منحنى عضوي من أسفل اليسار ليمين القمة** مع تجمعات = عقد المراحل
- كارت تقدم في المنتصف (~50%) · كروت عائمة (~77-84%) · **جزيرة تنقل عائمة في الأسفل** (~99%)
- ⚠️ ملاحظة: الصورة بألوان **بنفسجية** — والباليتة المعتمدة عندنا **خضراء**. القواعد (الجرامر) هي اللي هناخدها من الصورة، والألوان قرارك النهائي: نخليها خضراء جبلية ولا نتحول للبنفسجي الغروب (الخيار ج)؟
