## ٢. لوحة الألوان الملوكية الدقيقة (The Imperial OKLCH Color System)

نعتمد فضاء ألوان **`OKLCH`** الأحدث عالمياً لضمان ثبات التباين والنقاء البصري على جميع شاشات OLED و Super Retina:

```css
:root {
  /* ── الألوان الرئيسية والسيادة (Brand Anchors) ── */
  --gold-primary: oklch(84% 0.19 80.46);         /* ذهب كينباكو الملوكي للأزرار والألقاب */
  --gold-glow: oklch(89% 0.14 84.00);            /* توهج الذهب الشمسي الخفيف */
  --gold-metallic: linear-gradient(135deg, oklch(89% 0.14 84) 0%, oklch(84% 0.19 80.46) 50%, oklch(74% 0.17 76) 100%);

  /* ── الأسطح والعمق (Surfaces & Obsidian Void) ── */
  --bg-lacquer-black: oklch(7% 0.006 95);        /* خلفية الشاشة الفاحمة المريحة للعين */
  --bg-lacquer-deep: oklch(4% 0.004 95);         /* الانخفاضات العميقة والقوائم الجانبية */
  --bg-raised-surface: oklch(11% 0.006 95);      /* أسطح الكروت والبطاقات العائمة */
  --bg-subtle-glass: rgba(255, 255, 255, 0.04);  /* خلفية الزجاج الشفاف */

  /* ── الحدود المعدنية واللمسات الداخلية (Bezels & Hairlines) ── */
  --border-hairline: rgba(255, 255, 255, 0.08);  /* حد خارجي نحيف 1px */
  --border-gold-glow: rgba(229, 184, 66, 0.22);  /* حد ذهبي خافت للأبطال والتركيز */
  --inner-highlight: inset 0 1px 1px rgba(255, 255, 255, 0.12); /* شطفة الزجاج العلوية */

  /* ── ألوان الإشارات الحيوية (Semantic Statuses) ── */
  --color-focus-mint: oklch(76% 0.17 160);       /* زمرد التركيز والنجاح (جلسات النبض) */
```

## ٥. القواعد الصارمة لحركة النوابض والتفاعل (Emil Kowalski Motion Laws)

### ١. قاعدة بوابة التكرار (Frequency Gate):
* أي عنصر يُفتح **100+ مرة يومياً** (مثل لوحة المفاتيح أو فتح القوائم السريعة) $\rightarrow$ **صفر أنيميشن نهائياً (0ms Instant)** لمنع تعطيل العميل.
* العناصر العابرة (المنبثقات، الكروت، رسائل الشات) $\rightarrow$ حركة نوابض خفيفة من **150ms إلى 220ms**.

### ٢. محددات منحنيات الدخول والخروج (Easing Rules):
* ❌ **ممنوع نهائياً استخدام `scale(0)`**: لا شيء في العالم الحقيقي ينبثق من العدم؛ نبدأ دائماً من `scale(0.95)` مع `opacity: 0`.
* ❌ **ممنوع `ease-in` في واجهات المستخدم**: يسبب ثقلاً بصرياً؛ نستخدم دائماً الـ Ease-Out القوي:
```css
/* المنحنى الرسمي لواجهات Clan App */
--ease-out-fluid: cubic-bezier(0.23, 1, 0.32, 1);
--ease-spring-ios: cubic-bezier(0.32, 0.72, 0, 1);
```

### ٣. استجابة الضغط الفوري اللمسية (0ms Touch Response):
```css
/* انضغاط فيزيائي فوري عند لمس أي زر */
.luxury-btn:active {
  transform: scale(0.97);
  transition: transform 100ms var(--ease-out-fluid);
}
```

## ٦. القواعد الـ ٥٩ الصارمة لمنع القبح البصري (Anti-AI Slop Checklist)

1. ❌ **حظر التدرجات البنفسجية المكررة**: استبدالها بتدرجات الذهب الإمبراطوري (`--gold-metallic`) مع أسود الورنيش.
2. ❌ **حظر البطاقات المتداخلة داخل بعضها (Nested Cards)**: استبدالها بالمساحات البيضاء الذكية وفواصل الـ 1px الخافتة.
3. ❌ **حظر الخطوط المبتذلة المكررة** (مثل Arial و Inter الافتراضي) واستبدالها بالثلاثي الذهبي المعتمد.
4. ❌ **حظر الأيقونات السميكة الكرتونية**: استخدام خطوط أيقونات نحيفة بـ `1.5px stroke` (مثل Phosphor Light أو Remix Line).
5. ❌ **حظر المنحنيات الهزازة المبتذلة (Bounce Easing)**: استبدالها بفيزياء النوابض الانسيابية الطبيعية.
6. ✅ **احترام أطراف شاشات الهواتف (Safe Area Insets)**: استخدام `min-h-[100dvh]` و `env(safe-area-inset-bottom)` لمنع قفزات متصفحات الموبايل.
