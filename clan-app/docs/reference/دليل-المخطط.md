## أهم القرارات في التصميم

### 1. رصيدان للشرارات لا رصيد واحد
```prisma
sparksBalance     Int  // ينقص بالشراء
totalSparksEarned Int  // لا ينقص — للأوسمة
```
لو كان رصيداً واحداً، من يشتري فيديو يخسر تقدّمه في الأوسمة.

### 2. `SparkTransaction` سجل كامل
كل حركة (كسب أو صرف) تُسجَّل مع `balanceAfter`.
لو ظهر خلل في الأرقام، تعرف مصدره في ثوانٍ.

### 3. ثلاثة أعمدة لمدة الجلسة
```prisma
plannedMin        // المخطط
clientReportedMin // ما قاله الموبايل (قد يكون أوفلاين)
serverVerifiedMin // ما يعتمده الخادم ← الشرارات تُحسب منه
```
هذا ما يجعل "الثقة مع سقف" ممكنة تقنياً.

### 4. `Clan.maxMembers` أصبح اختيارياً
`null` = بلا حد (العشائر العامة). رقم = العشائر الخاصة.

### 5. `Domain` enum لا نص حر
يمنع "برمجة" و"برمجه" و"Programming" من صنع ثلاث عشائر.

### 6. `User.timezone` إلزامي
الستريك يُحسب بتوقيت المستخدم. بدونه تنكسر السلاسل عند منتصف ليل UTC.

### 7. الرسائل في MongoDB — البيانات الوصفية في Postgres
`Conversation` و `ConversationParticipant` في Postgres (علاقات وصلاحيات).
نص الرسائل في Mongo (حجم كبير، بلا علاقات).

### 8. `AiUsageLog` بمفتاح `(userId, date)`
عدّاد يومي ذرّي لفرض حد الـ 5 رسائل المجانية.

### 9. `Payment.amount` عدد صحيح
بالقروش لا بالجنيهات — الفواصل العشرية في المال مصدر أخطاء لا ينتهي.

## ما تغيّر عن المخطط القديم

| قبل | بعد | السبب |
|---|---|---|
| `field String?` | `domain Domain` + `specialty String?` | إلزامي + منضبط |
| `sparksCount` | `sparksBalance` + `totalSparksEarned` | عملة تُصرف |
| `DailyMirror` | `JournalEntry` (5 حقول + مشفّرة) | مواصفات v2.1 |
| `Task.priority Int` | `TaskPriority` enum | 3 فئات محددة |
| `TaskReward` | ❌ حُذف | `SparkTransaction` يغطيه |
| `ClanSession` | `PulseSession` + `PulseReservation` | نظام الحجز |
| `ClanAchievement` | `Achievement` + `UserAchievement` | 12 وساماً بمستويات |
| `maxMembers Int` | `Int?` | العامة بلا حد |
| — | +18 جدولاً جديداً | الأقسام الجديدة |
