## ٢. الأوامر التشغيلية المباشرة (One-Command Operations)

### ١. أخذ نسخة احتياطية فورية:
```bash
npm run db:backup
```
* **ماذا يحدث في الخلفية؟**:
  1. يتصل السيرفر بقاعدة `PostgreSQL 17` وينفذ `pg_dump --clean --if-exists`.
  2. يتم ضغط الناتج فورياً بأقصى مستوى ضغط `gzip -9` وحفظه في مجلد `backups/`.
  3. يتم حساب بصمة التشفير الرقمية `SHA-256` وحفظها في ملف `.sha256` مرافق.
  4. يتم تطبيق سياسة التدوير وحذف النسخ القديمة الزائدة.

---

### ٢. استعادة قاعدة البيانات والتعافي من الكوارث:
```bash
npm run db:restore
```
* **ماذا يحدث في الخلفية؟**:
  1. يقوم السكريبت بقراءة أحدث نسخة احتياطية في `backups/`.
  2. يتحقق من تطابق بصمة `SHA-256` لضمان عدم تلف الملف.
  3. يفك الضغط ويعيد بناء الجداول والبيانات في PostgreSQL في **~0.5 ثانية**.

---

## ٣. سياسة الاستبقاء والتدوير الذكي (Smart Retention Policy)

* **النسخ اليومية**: الاحتفاظ بنسخ آخر **٧ أيام**.
* **النسخ الأسبوعية**: الاحتفاظ بنسخة كل أسبوع لآخر **٤ أسابيع**.
* **النسخ الشهرية**: الاحتفاظ بنسخة كل شهر لآخر **١٢ شهراً**.
* **الحذف التلقائي**: مسح النسخ الأقدم لتوفير مساحة التخزين وحماية القرص من الامتلاء.
