# 🔴 الحقيقة أولاً

## ما لا يمكن فعله

**تطبيقك لا يستطيع الكتابة في تطبيق الساعة (Clock App).**

هذا ليس قصوراً في المكتبات — بل **قرار أمني** من Google و Apple.
لو كان ممكناً، لأضاف كل تطبيق منبهات في هاتفك بلا إذنك.

| العملية | أندرويد | iOS |
|---|---|---|
| كتابة مباشرة في تطبيق الساعة | ❌ | ❌ |
| قراءة منبهات النظام | ❌ | ❌ |
| **فتح شاشة إضافة منبه** | ✅ | ❌ |
| جدولة في نظام التشغيل | ✅ | ✅ |

## لماذا AlarmManager يكفي فعلاً

```
منبه تطبيق الساعة              منبهك عبر AlarmManager
───────────────────            ──────────────────────
مخزّن في نظام التشغيل      ←→   مخزّن في نظام التشغيل ✅
يرنّ والتطبيق مقفول         ←→   يرنّ والتطبيق مقفول ✅
يرنّ بلا إنترنت             ←→   يرنّ بلا إنترنت ✅
يعيش بعد إعادة التشغيل      ←→   بشرط BOOT_COMPLETED
```

**الفرق الوحيد:** تطبيق الساعة يعيد جدولة نفسه تلقائياً بعد الإقلاع.
منبهك يحتاج مستقبِلاً يفعل الشيء نفسه — وهو سطران في المانيفست.

# الطبقة 1 — AlarmManager

مشروحة كاملة في `دليل-المنبه-المحلي.md`. الخلاصة:

```js
await notifee.createTriggerNotification(
  {
    android: {
      category: AndroidCategory.ALARM,      // يعامله النظام كمنبه
      fullScreenAction: { id: 'wake' },     // شاشة كاملة والجهاز مقفول
      loopSound: true,
      ongoing: true,                        // لا يُمسح بالسحب
    },
    ios: { critical: true, sound: 'alarm.wav' },
  },
  {
    type: TriggerType.TIMESTAMP,
    timestamp: fireDate.getTime(),
    repeatFrequency: RepeatFrequency.WEEKLY,
    alarmManager: { allowWhileIdle: true },  // يتجاوز Doze
  },
);
```

# الطبقة 2 — النجاة من إعادة التشغيل

## المانيفست

```xml
<uses-permission android:name="android.permission.RECEIVE_BOOT_COMPLETED" />
<uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM" />
<uses-permission android:name="android.permission.USE_EXACT_ALARM" />

<application>
  <receiver
    android:name="app.notifee.core.ReceiverService"
    android:exported="false"
    android:directBootAware="true">
    <intent-filter>
      <action android:name="android.intent.action.BOOT_COMPLETED" />
      <action android:name="android.intent.action.QUICKBOOT_POWERON" />
      <action android:name="android.intent.action.MY_PACKAGE_REPLACED" />
      <!-- أجهزة صينية ترسل أحداثاً مختلفة -->
      <action android:name="com.htc.intent.action.QUICKBOOT_POWERON" />
    </intent-filter>
  </receiver>
</application>
```

> `directBootAware="true"` يجعل المستقبِل يعمل **قبل** فتح قفل الجهاز
> بعد الإقلاع — مهم لمن يعيد التشغيل ليلاً.

## شبكة أمان مزدوجة

حتى مع المستقبِل، أعد الجدولة عند كل فتح:

```js
// App.js
useEffect(() => {
  rescheduleAll();

  const sub = AppState.addEventListener('change', (s) => {
    if (s === 'active') rescheduleAll();
  });

  return () => sub.remove();
}, []);
```

**التكلفة صفر** — إعادة الجدولة عملية محلية سريعة.

# الطبقة 3 — زر «أضف لمنبه الهاتف»

هذا ما طلبته: نسخة في تطبيق الساعة نفسه.

## أندرويد — يعمل فعلاً

```js
import { Linking, Platform } from 'react-native';

/**
 * يفتح تطبيق الساعة بشاشة إضافة منبه مملوءة مسبقاً.
 *
 * ⚠️ المستخدم يضغط «حفظ» بنفسه — لا يمكن تخطي ذلك.
 *    هذا قيد أمني في أندرويد لا حيلة فيه.
 */
export const addToSystemClock = async (alarm) => {
  if (Platform.OS !== 'android') return false;

  const [hour, minute] = alarm.time.split(':').map(Number);

  // أيام أندرويد: الأحد = 1 ... السبت = 7
  const androidDays = alarm.days.map((d) => d + 1);

  const url =
    `intent:#Intent;action=android.intent.action.SET_ALARM;` +
    `i.android.intent.extra.alarm.HOUR=${hour};` +
    `i.android.intent.extra.alarm.MINUTES=${minute};` +
    `S.android.intent.extra.alarm.MESSAGE=${encodeURIComponent('منبه المعركة')};` +
    `B.android.intent.extra.alarm.SKIP_UI=false;` +
    `end`;

  try {
    await Linking.openURL(url);
    return true;
  } catch {
    return false;
  }
};
```

**تجربة المستخدم:**
```
[ ⏰ أضف لمنبه الهاتف ]  ← يضغط
        ↓
يفتح تطبيق الساعة بالوقت مملوءاً
        ↓
المستخدم يضغط «حفظ»
        ↓
منبه حقيقي في تطبيق الساعة 🎯
```

## المكتبة الأنظف

```bash
npm install react-native-android-alarm-clock
```

```js
import AlarmClock from 'react-native-android-alarm-clock';

AlarmClock.setAlarm({
  hour: 6,
  minutes: 0,
  message: 'منبه المعركة',
  days: [1, 2, 3, 4, 5],   // الأحد = 1
  skipUi: false,           // true يتطلب إذناً خاصاً
});
```

## iOS — لا سبيل

لا يوجد API لفتح شاشة إضافة منبه. البديل الوحيد:

```js
// إرشاد نصي فقط
Alert.alert(
  'أضف المنبه يدوياً',
  'افتح تطبيق الساعة ← منبه ← إضافة\nالوقت: 06:00\nالتكرار: الأحد–الخميس',
  [{ text: 'نسخ الوقت', onPress: () => Clipboard.setString('06:00') }],
);
```

# ⚠️ عيب الطبقة الثالثة

منبه تطبيق الساعة **منفصل تماماً** عن تطبيقك:

| | منبهك | منبه الساعة |
|---|---|---|
| يفتح شاشة الاستيقاظ | ✅ | ❌ |
| يطلب حل المسألة | ✅ | ❌ |
| يمنح شرارات | ✅ | ❌ |
| يبني السلسلة | ✅ | ❌ |
| يشارك في التحدي | ✅ | ❌ |

**فهو تأمين على الاستيقاظ فقط، لا بديل عن منبه التطبيق.**

## الصياغة الصحيحة في الواجهة

```
✅ منبهك مضبوط على 06:00
   يرنّ حتى لو أُغلق التطبيق

   [ ⏰ أضف نسخة لمنبه الهاتف ]
   تأمين إضافي — لكن حل المسألة والشرارات
   يتمّان من داخل التطبيق فقط
```

# 📊 مصفوفة الموثوقية

| السيناريو | AlarmManager | + Boot Receiver | + منبه الساعة |
|---|---|---|---|
| التطبيق في الخلفية | ✅ | ✅ | ✅ |
| التطبيق مُغلق بالسحب | ✅ | ✅ | ✅ |
| بلا إنترنت | ✅ | ✅ | ✅ |
| **بعد إعادة التشغيل** | ❌ | ✅ | ✅ |
| **حُذف التطبيق** | ❌ | ❌ | ✅ |
| مدير بطارية عدواني | ⚠️ | ⚠️ | ✅ |
| وضع عدم الإزعاج | ✅* | ✅* | ✅ |

`*` يحتاج `bypassDnd` في أندرويد و Critical Alerts في iOS.

# 🧪 خطة اختبار الضمان

نفّذها بالترتيب — الرابع هو الحاسم:

```
1️⃣  منبه بعد 3 دقائق · اقفل التطبيق بالسحب
    → يجب أن يرنّ

2️⃣  منبه بعد 3 دقائق · وضع الطيران
    → يجب أن يرنّ

3️⃣  منبه بعد 3 دقائق · «عدم الإزعاج»
    → يجب أن يرنّ (يحتاج bypassDnd)

4️⃣  منبه بعد 5 دقائق · أعد تشغيل الهاتف · لا تفتح التطبيق
    → يجب أن يرنّ   ← الاختبار الحاسم

5️⃣  اترك الهاتف ساعتين بلا لمس · منبه
    → يجب أن يرنّ (اختبار Doze)

6️⃣  على Xiaomi أو Huawei تحديداً · كرّر 4️⃣
    → إن فشل: مدير البطارية — اطلب الاستثناء
```

**لو فشل 4️⃣:** المشكلة في `RECEIVE_BOOT_COMPLETED` أو المستقبِل.
**لو فشل 5️⃣:** المشكلة في `allowWhileIdle`.
**لو فشل 6️⃣ فقط:** مدير البطارية — الحل في الدليل الآخر.

# ✅ التوصية النهائية

**ابنِ الطبقتين 1 و 2 — هما الأساس.**
تغطيان كل حالة واقعية: مقفول · بلا نت · بعد إعادة التشغيل.

**أضف الطبقة 3 كزر اختياري** لمن يريد تأميناً مضاعفاً — مع توضيح
أن الشرارات وحل المسألة من التطبيق فقط.

> **لا تعتمد على الطبقة 3 وحدها.** منبه تطبيق الساعة لا يعرف شيئاً
> عن تطبيقك — لا شرارات ولا سلسلة ولا تحدٍّ جماعي.
