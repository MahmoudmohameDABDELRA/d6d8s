# 📜 مخطط تطوير الإشعارات المنبثقة العائمة (Telegram-Style Popups) وتناوب الأسئلة وتنبيه الـ 5 دقائق
**Clan App — Floating Centered Popups, Notification Chime & Sequential Check-in Questions**

---

## 🎯 ١. الأهداف المطلوب تنفيذها
1. **تحديث الإشعارات المنبثقة (Popups)** لتصبح بطاقات عائمة فاخرة في **منتصف الشاشة تماماً** (Centered Floating Glass Card)، شبيهة بإشعارات تيليجرام وآبل الفاخرة، مع أنيميشن انسيابي سلس (Spring Bounce 60 FPS).
2. **إضافة صوت إشعار راقٍ (Notification Chime Synth)**: نغمة جرس صوتية ثنائية التردد (880Hz -> 1320Hz) تنطلق تلقائياً فور ظهور الـ Popup.
3. **التدوير والتناوب الحتمي لأسئلة ما بعد المهمة (Sequential 10-Question Cycle)**:
   - الانتقال من الاختيار العشوائي إلى التدوير الرقمي المتسلسل: إذا ظهر السؤال رقم (1)، يظهر السؤال (2) في المهمة التالية، ثم (3) حتى (10)، ثم يعود لـ (1) تلقائياً، مع منع التكرار المتتالي نهائياً.
4. **تعديل التنبيه المسبق للمهمة ليصبح قبل ٥ دقائق بالضبط**:
   - نص الإشعار الصريح: `"استعد يا بطل! عندك مهمة [اسم المهمة] بعد ٥ دقائق ⏰"`.
   - إلحاق النكش الخفيف والنصيحة الذكية السريعة حسب نوع المهمة.

## 🎨 ٢. الهيكل البصري للـ Popup العائم (Telegram-Style Centered Box)

```css
.telegram-floating-popup-card {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%) scale(1);
  width: 90%;
  max-width: 360px;
  background: rgba(20, 23, 33, 0.96);
  backdrop-filter: blur(20px);
  border: 1.2px solid rgba(229, 184, 66, 0.4);
  border-radius: 22px;
  padding: 20px;
  box-shadow: 0 12px 45px rgba(0, 0, 0, 0.85), 0 0 25px rgba(229, 184, 66, 0.18);
  animation: telegramPopupSpring 0.35s cubic-bezier(0.34, 1.56, 0.64, 1);
  z-index: 10000;
}
```

## 🔔 ٣. محرك الصوت التخليقي لنغمة الإشعار (`playNotificationChime`)
- استخدام Web Audio API لتوليد نغمة تيليجرام النقية دون الاعتماد على ملفات خارجية قد تفشل في التحميل:
  - **الموجة الأولى**: 880 هرتز (A5) لمدة 120ms.
  - **الموجة الثانية**: 1320 هرتز (E6) لمدة 250ms مع منحنى هبوط أسي ناعم (Exponential Decay).

## ⏰ ٥. تنبيه الـ ٥ دقائق قبل المهمة
- **التوقيت**: قبل الموعد بـ ٥ دقائق.
- **الهيكل المعتمد**:
  1. **النداء والتنبيه الصريح**: `"استعد يا بطل! عندك مهمة [اسم المهمة] بعد ٥ دقائق ⏰"`.
  2. **النكش الخفيف**: مناسب للمجال (فيزياء، رياضة، برمجة، دراسة).
  3. **النصيحة التكتيكية السريعة**: تريكة فورية للبدء بقوة.
  4. **زر الانطلاق الفوري**: `[ 🔥 جاهز وانطلق لمساحة التركيز ]`.
